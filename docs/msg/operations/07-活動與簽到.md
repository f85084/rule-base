# 07 活動與簽到

## 一般人員操作

**這頁做什麼**：在 `/CheckIn`、`/GameManage`、`/FrameMergeActivity` 查看或依授權維護簽到、遊戲與照片合成活動。

**開始前**：準備活動期間、合規素材、獎項／庫存與負責人覆核；建立、發布、停用、刪除與庫存調整通常不是一般客服的日常權限。

**照著做**：

1. 在活動列表找到正確活動，核對名稱、期間與狀態。預期結果：進入正確明細而不是相鄰活動。
2. 簽到在 `/CheckIn` 核對印章／注意事項；遊戲在設定頁核對獎項／庫存；照片合成核對壓框圖。預期結果：必要欄位與素材完整。
3. 依授權儲存、發布或停用，完成後回列表／明細確認狀態。預期結果：後台狀態與交辦內容一致。

**完成確認**：活動資料、素材與狀態可回查；後台保存不等於 B2C 使用者端已能參與。

**常見問題**：列表空白先確認日期、狀態與權限；單一素材或報表失敗時記錄活動與時間，不要直接判定整個活動服務故障。

## 敘述狀態與查核界線

- **current（來源整理）**：`/CheckIn` 管理簽到活動，`/GameManage` 與明細頁管理遊戲，`/FrameMergeActivity` 與明細頁管理照片合成活動。
- **historical（歷史）**：需求快照中列出的活動欄位、獎項機率、庫存、印章或報表功能，不能當成目前一定可用或已發布。
- **inference（推論）**：先確認活動期間、素材、獎項／庫存與狀態，再發布或停用，是活動管理的基本覆核順序。
- **runtime unknown（執行期未確認）**：B2C 參與、活動對外呈現、抽獎結果、報表內容、發布同步與目前角色按鈕，需依當期環境確認。

## 適用人員與入口

入口是 `/CheckIn`、`/GameManage`、`/GameManage/Setting/:eventId`、`/FrameMergeActivity`、`/FrameMergeActivity/:activityId`。一般人員依交辦查詢或執行明確步驟；建立、發布、停用、刪除與庫存調整通常需要活動負責人或管理者權限。

## 正常流程

1. 簽到：在 `/CheckIn` 找到活動，確認基本資料、期間、印章排列與注意事項；需要時依頁面下載名單或報表。
2. 遊戲：在 `/GameManage` 選擇活動，於設定頁核對期間、獎項、機率與庫存，再依授權啟用或停用。
3. 照片合成：在 `/FrameMergeActivity` 建立／編輯活動，核對期間與壓框圖素材，再依授權發布或停用。
4. 每次儲存、發布、停用或下載後回列表／明細確認狀態與活動名稱，並把變更交接給負責人。

## 完成判斷

活動、印章／獎項／壓框圖與狀態在後台畫面正確顯示，報表下載後可開啟且符合條件。後台保存不等於使用者端已能參與，也不等於外部通知已送達。

## 權限與前置

需要活動資料、合規素材、獎項／庫存確認與相應管理權限。刪除、發布、停用與庫存調整前應有指定負責人覆核；不要用正式活動做未授權測試。

## 影響與限制

發布／啟用會改變對外狀態，停用會停止活動，刪除或調整庫存可能難以復原。需求狀態如「待測試」不能被改寫為已部署或已驗證。

## 第一個排錯

先核對活動頁、活動名稱、期間、狀態、必要素材與報表條件，再重新開啟明細。若功能或按鈕與文件不同，保留非敏感畫面訊息與時間，請管理者／需求負責人確認當期版本。

## 頁面別子流程與 route-specific 排錯

### `/CheckIn`：簽到活動管理

1. **頁面／欄位判讀**：分開確認活動清單、活動期間、印章排列、注意事項與報表／名單入口；清單狀態不等於使用者端可簽到。
2. **資料來源／合併邊界**：活動基本資料、印章設定、注意事項與簽到報表是不同資料區塊；報表結果不自動代表活動設定已對外同步。
3. **寫入／對外副作用**：新增／修改活動、印章或注意事項會改變活動內容；下載主要是讀取，但檔案可能含業務資料，發布／啟用依當期授權。
4. **空資料／部分失敗判讀**：活動清單空白、活動有但印章空白、報表無資料與部分欄位儲存失敗分開處理；不要直接判定整個活動服務故障。
5. **第一個排錯**：先核對活動期間、狀態與明細頁，再重新查詢單一活動；仍不符時提供活動識別以外的非敏感資訊給管理者。

### `/GameManage`：遊戲活動列表

1. **頁面／欄位判讀**：查看活動名稱、期間、狀態、獎項／設定入口與列表動作，先確認選到正確活動再進明細。
2. **資料來源／合併邊界**：活動列表、遊戲設定、抽獎／獎項資料與使用者端參與是不同邊界；列表狀態不等於抽獎結果或庫存已同步。
3. **寫入／對外副作用**：建立、啟用、停用或刪除活動會影響對外活動；送出前核對期間與覆核人，不在正式活動做未授權測試。
4. **空資料／部分失敗判讀**：列表空白、單一活動缺設定、活動狀態未更新與使用者端不可用分開記錄；不能用一個空列表推論所有活動消失。
5. **第一個排錯**：先用活動名稱／期間縮小查詢，確認帳號權限，再進 `GameSetting` 查驗設定。

### `/GameManage/Setting/:eventId`：遊戲設定

1. **頁面／欄位判讀**：核對路徑中的 `eventId` 與活動名稱，逐項檢查期間、獎項、機率、庫存與啟用狀態；不要只看儲存按鈕。
2. **資料來源／合併邊界**：設定頁資料依附 `/GameManage` 活動主檔；獎項／庫存與使用者端抽取結果不在同一讀取邊界。
3. **寫入／對外副作用**：修改機率、獎項或庫存可能改變活動規則與成本；發布／啟用前須由活動負責人覆核。
4. **空資料／部分失敗判讀**：活動識別錯誤、單一設定區塊空白、儲存部分失敗與活動端未更新分開排查；不要用猜測 ID 重試。
5. **第一個排錯**：回 `/GameManage` 確認活動與狀態，再以正確 `eventId` 重開設定頁並記錄欄位錯誤。

### `/FrameMergeActivity`：照片合成活動列表

1. **頁面／欄位判讀**：確認活動名稱、期間、狀態、壓框圖／素材入口與報表動作，再進入單一活動明細。
2. **資料來源／合併邊界**：活動主檔、壓框圖素材、明細設定與使用者端合成結果分開；列表存在不等於素材已可用。
3. **寫入／對外副作用**：新增、編輯、發布、停用或刪除活動／素材會影響對外活動；先核對活動期間與檔案版本。
4. **空資料／部分失敗判讀**：列表空白、活動有但素材缺失、報表空白與使用者端未呈現分開處理；不要把單一素材錯誤當成列表故障。
5. **第一個排錯**：先核對活動狀態與素材格式，再進明細頁重查；必要時請活動負責人確認版本。

### `/FrameMergeActivity/:activityId`：照片合成活動明細

1. **頁面／欄位判讀**：以 `activityId` 核對活動名稱、期間、壓框圖與發布／停用狀態；每個素材欄位要逐一確認。
2. **資料來源／合併邊界**：明細欄位與列表主檔相連，壓框圖檔案與外部使用者端合成結果仍是不同邊界。
3. **寫入／對外副作用**：儲存或發布明細會改變活動內容；停用／刪除可能影響正在使用的活動，不要把預覽成功當成正式發布。
4. **空資料／部分失敗判讀**：明細載入空白、單一壓框圖失敗、儲存成功但列表狀態未變與外部未更新分開記錄。
5. **第一個排錯**：先回列表確認 `activityId` 與狀態，再重新開啟明細；仍失敗時保留檔案格式與畫面提示。
