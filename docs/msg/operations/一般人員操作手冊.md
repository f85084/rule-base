# MSG 一般人員操作手冊

## 第一次使用先照這裡做

這一頁是入口索引，不是技術手冊。先在「工作入口」選擇工作目的，再開啟對應單頁文件；單頁文件會把入口、角色、開始前條件、畫面操作、預期結果、完成確認與常見問題放在一起。需求、business-flow 與技術補充留在各頁末尾，第一次操作不需要先閱讀。

1. 先確認目前是 MSG 後台、使用中的帳號與要處理的客戶／名單。
2. 從下表開啟最接近的工作文件，先讀「適用人員與入口」及「權限與前置」。
3. 依「正常流程」逐步操作；每一步都以畫面出現的結果確認後再進下一步。
4. 送出、發布、刪除、轉派或群發前停下來再核對客戶、範圍與內容。
5. 依「完成判斷」確認結果；遇到問題先做該頁「第一個排錯」，再提供頁面、時間與非敏感提示給管理者。

本頁是 MSG B2E 一般人員的短索引。請先依工作目的選一份操作文件，再依該文件的入口、流程與完成判斷操作；本頁不重複八個流程的完整步驟。

## 敘述狀態與查核界線

- **current（來源整理）**：下表的頁面路徑、L2/L3 業務方案與需求入口，依目前儲存的 MSG 索引與文件整理。
- **historical（歷史）**：Redmine 需求快照中的狀態、舊欄位或舊規則，只表示曾被記錄，不能當成目前已部署功能。
- **inference（推論）**：八份文件依 B2E L3 方案與相關 L2 頁面分組，方便一般人員找入口；分組不是權限核准表。
- **runtime unknown（執行期未確認）**：帳號可見頁面、按鈕文字、資料同步、外部 LINE 送達、報表正確性與部署版本，仍以目前環境畫面、公告與管理者確認為準。

## 共通安全提醒

1. 先確認目前帳號、客戶／受眾、日期範圍與功能頁，再按送出、發布、停用、刪除或群發。
2. 看不到頁面或按鈕時，先視為權限或環境差異；不要用猜測的路徑、別人的帳號或技術 API 繞過限制。
3. 查不到資料可能是條件未命中、資料尚未同步、權限範圍不同或服務錯誤。保留頁面、條件、時間與非敏感錯誤訊息，依操作文件的第一個排錯方向回報。
4. 不要在工單、文件或聊天貼上密碼、Token、完整登入網址、未遮罩個資或完整客戶名單。

## 一般選擇流程

1. 先在「工作入口」依目的選擇一份文件與對應頁面。
2. 依文件的入口、正常流程與權限／前置完成操作，遇到寫入或對外動作先停下來覆核。
3. 依完成判斷確認畫面結果；若不符合，先做該文件列出的第一個排錯，再回報非敏感證據。

## 完成判斷

已選到正確的單頁文件，完成該文件的正常流程，並依其完成判斷確認結果。需求單狀態或索引有連結，不等於功能已部署或已在 runtime 驗證。

## 權限與前置

每份單頁文件都以一般人員可操作範圍為主，管理者頁面、共用設定與群發／發布動作仍需相應角色及覆核；實際權限以目前帳號與畫面為準。

## 影響與限制

本頁只負責導航，不取代單頁文件的資料合併、寫入副作用、異常排查與來源說明。若來源文件、需求快照與現行 UI 不一致，保留差異並依當期環境確認。

## 第一個排錯

先確認工作目的、目前帳號、頁面路徑與文件入口；再回到對應單頁文件的第一個排錯。不要用不存在的路徑、他人帳號或技術 API 代替權限流程。
