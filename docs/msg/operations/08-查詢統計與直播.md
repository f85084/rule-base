# 08 查詢統計與直播

## 一般人員操作

**這頁做什麼**：在 `/Dialog` 查對話、`/Metrics`／`/MessagesMetrics` 看統計、`/Stream` 查或維護直播，以及 `/AiCostReport` 查詢費用。

**開始前**：準備日期範圍、客戶／專員條件與報表用途；直播預告、測試訊息、機器人規則與模型單價交由指定管理者操作。

**照著做**：

1. 先選正確功能頁與日期，再填必要篩選條件。預期結果：查詢條件與頁面目的相符。
2. 送出查詢後先核對日期、筆數、單位與明細，再下載報表。預期結果：檔案可開啟且可追溯條件。
3. 直播設定只在覆核後修改；費用頁只查詢或由授權人維護單價。預期結果：不把儲存按鈕當成外部同步證明。

**完成確認**：查詢／報表符合所選條件；直播對外呈現、資料延遲與 AI 費用正確性仍需當期 runtime 證據。

**常見問題**：空結果先用最小日期／條件重查；單一圖表或直播區塊失敗時記錄頁面、時間與提示，請管理者核對權限與同步。

## 敘述狀態與查核界線

- **current（來源整理）**：`/Dialog` 查詢對話，`/Metrics` 與 `/MessagesMetrics` 查看統計，`/Stream` 維護直播，`/AiCostReport` 查詢 AI 費用。
- **historical（歷史）**：需求頁中的圖表欄位、報表範圍、直播設定、模型單價或通知描述，僅是需求／來源版本，不能當成目前部署保證。
- **inference（推論）**：先選對頁面與日期，再核對篩選條件、筆數與明細，適合避免把空結果當成系統故障。
- **runtime unknown（執行期未確認）**：統計資料正確性、資料延遲、直播對外同步、預告送達、AI 費用計算與目前權限，需依當期畫面、報表與管理者確認。

## 適用人員與入口

一般人員可依授權使用查詢與報表；直播活動、預告、機器人留言、費用單價與共用設定通常由管理者負責。入口為 `/Dialog`、`/Metrics`、`/MessagesMetrics`、`/Stream`、`/AiCostReport`。

## 正常流程

1. 先選擇目的頁與日期範圍；依頁面提供的客戶、專員、關鍵字或追蹤條件縮小範圍。
2. 執行查詢後，先確認結果的日期、條件、筆數與資料單位，再開啟明細或下載報表。
3. 用 `/Dialog` 還原對話脈絡；用 `/Metrics`、`/MessagesMetrics` 查看趨勢、好友或訊息發送統計。
4. 進入 `/Stream` 修改活動、商品順序、預告或機器人留言前，先確認目前活動與覆核人；不確定時只查詢不送出。
5. 在 `/AiCostReport` 查詢費用時，核對期間、模型／報表範圍；模型單價等管理設定不要自行修改。

## 完成判斷

查詢結果與所選日期／條件一致，明細或報表可開啟且能交給後續核對。直播或費用設定是否已影響外部行為，仍需以當期系統結果確認，不能只以儲存按鈕判定。

## 權限與前置

需要正確日期、查詢範圍與頁面權限；報表可能含業務資料，應依公司規範保存與分享。直播預告、測試訊息、機器人規則與模型單價涉及營運或成本，交由指定管理者操作。

## 影響與限制

一般查詢與下載以讀取為主；直播設定、預告／測試訊息、機器人規則與 AI 單價可能改變對外行為或成本。空白結果不代表資料不存在，也不表示外部平台沒有收到訊息。

## 第一個排錯

先記錄頁面、日期、篩選條件、報表類型與非敏感提示，再用最小條件重新查詢。若仍無結果，請管理者核對權限、資料範圍與同步狀態；不要擴大下載或分享範圍。

## 頁面別子流程與 route-specific 排錯

### `/Dialog`：對話查詢

1. **頁面／欄位判讀**：先選日期，再依頁面提供的客戶、專員、關鍵字或追蹤條件查詢；分開看列表、對話明細與下載報表。
2. **資料來源／合併邊界**：對話列表、訊息明細與報表下載可能是不同查詢結果；列表空白不代表所有歷史資料或其他統計頁都空白。
3. **寫入／對外副作用**：一般查詢與下載以讀取為主，但下載檔案可能含業務資料；不要把查詢結果回寫成客戶資料。
4. **空資料／部分失敗判讀**：條件未命中、單一對話缺明細、報表下載失敗與服務錯誤分開處理；不以零筆直接判定資料遺失。
5. **第一個排錯**：用最小日期／條件重查，記錄頁面、條件與時間，再請管理者核對查詢權限或資料範圍。

### `/Metrics`：資料統計

1. **頁面／欄位判讀**：先確認統計類型、日期區間、圖表／表格單位與篩選條件；圖表與明細數值不要在不同期間直接比較。
2. **資料來源／合併邊界**：好友、封鎖／解封、連結點擊等指標各有資料範圍；一個指標空白不等於整頁或訊息統計故障。
3. **寫入／對外副作用**：查詢通常不寫入，但匯出檔案可能含營運資料；不得把圖表數值當成已驗證的外部平台數據。
4. **空資料／部分失敗判讀**：日期無資料、單一圖表載入失敗、圖表與表格不同及統計延遲分開記錄；不要自行補算成正式報表。
5. **第一個排錯**：先核對日期、時區／篩選條件與目前帳號，再重查單一指標並保留畫面提示。

### `/MessagesMetrics`：訊息統計

1. **頁面／欄位判讀**：分開確認訊息類型、專員發送量、日期與統計單位；不要把訊息數直接當成送達數。
2. **資料來源／合併邊界**：訊息發送統計、對話查詢與外部平台送達結果是不同資料鏈；本頁數值不自動合併 `/Dialog` 明細。
3. **寫入／對外副作用**：查詢／下載主要是讀取；下載資料要依權限保存，不應拿來重送訊息。
4. **空資料／部分失敗判讀**：單一訊息類型空白、某專員缺資料、統計與對話筆數不同或資料延遲分開判斷。
5. **第一個排錯**：先縮小日期與訊息類型，重新查詢並記錄統計單位，再請管理者確認資料範圍。

### `/Stream`：直播設定

1. **頁面／欄位判讀**：核對直播活動、商品順序、片語、預告與機器人留言等區塊；先確認目前活動再修改單一設定。
2. **資料來源／合併邊界**：直播主檔、商品／片語、預告與留言規則是不同設定邊界；後台儲存不等於直播端或外部平台已同步。
3. **寫入／對外副作用**：修改活動、發布預告、發送測試訊息或變更機器人規則可能改變對外行為；非指定管理者只查詢。
4. **空資料／部分失敗判讀**：活動列表空白、單一設定區塊空白、儲存成功但直播端未變與預告送出失敗分開排查；不要重複發送。
5. **第一個排錯**：先核對活動狀態、設定區塊與時間，再記錄非敏感提示請管理者確認同步／權限。

### `/AiCostReport`：AI 費用報表

1. **頁面／欄位判讀**：確認日期、模型／費用欄位、查詢條件與匯出範圍；模型單價設定與費用查詢是不同權限視角。
2. **資料來源／合併邊界**：費用報表、AI 使用量、模型單價與外部帳單不自動視為同一來源；報表空白不等於沒有任何 AI 使用。
3. **寫入／對外副作用**：查詢／下載主要是讀取；修改模型單價或共用費用設定會影響後續成本計算，僅由指定管理者操作。
4. **空資料／部分失敗判讀**：日期無資料、單一模型缺費用、匯出失敗與單價未更新分開記錄；不能用需求頁數字替代當期報表。
5. **第一個排錯**：先核對日期、模型與帳號權限，再重新查詢最小範圍；仍不符時保留報表條件請管理者核對資料來源。
