# CSP 網站頁面用途索引

用途說明來源：`/home/art/openab-repos/project-docs/projects/CSP/data/business-flows/L2/`。
本文件先提供簡要頁面用途，作為需求單分類的人工校對依據；詳細流程仍以 project-docs 的 L2 文件為準。
