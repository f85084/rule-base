# CSP 文件索引

完整的 CSP 業務流程與技術解析以 `project-docs` 為主要來源；本目錄只保存延伸的操作、規則、排錯與測試資料文件。

## 目錄

- `operations/`：[日常操作與系統使用說明](operations/MI維運操作入口.md)、軟體電話與音檔操作
- `rules/`：規則與業務限制快查
- `troubleshooting/`：[排錯資料說明](troubleshooting/README.md)與症狀導向排查文件
- `test-data/`：測試時要準備或輸入系統的資料與環境索引
- `test-cases/`：可執行測試案例與預期結果
- `requirements/`：需求單與來源文件對照
