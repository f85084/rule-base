# 小m使用紀錄

## 敘述狀態與查核界線

- **現行事實**：本頁正文依目前列出的頁面用途、操作流程與來源整理。
- **runtime 未確認**：未在目前環境實際驗證的角色按鈕、API 回應、資料同步、保存期限與版本差異，不視為目前保證；以當期 UI、API 與授權設定為準。

本篇是 CSP `/DocumentQARecord` 小m問答使用紀錄查詢入口，供維運或管理人員查詢問答紀錄月報範圍與單筆明細。此頁是純查詢流程，不會修改文件、FAQ、Qdrant 或問答紀錄。

## 1. 權限與資料邊界

- 登入後可查詢，實際可見資料與頁面按鈕以目前帳號權限及環境為準。
- 清單查詢會並行取得問答紀錄、啟用使用者與文件標籤，再補上建立者／標籤顯示名稱；這些補值不是額外的資料異動。
- 明細由問答紀錄、文件與段落資料整理成 `DocInfos`、`AiRecordInfos`；不要把畫面整理後的物件當成單一原始資料表。
- 本頁沒有匯出、重跑、刪除或修正問答紀錄的 API；月報需求以日期區間查詢結果為準，不自行宣稱已產生報表檔。

## 2. 查詢紀錄清單

1. 開啟 `/DocumentQARecord`，設定頁面提供的日期／文件等查詢條件與分頁。
2. 執行 `POST api/DocumentQaRecord/QueryDocumentQaRecords`。
3. 依清單核對問答紀錄、建立者與標籤名稱；後端會另外查啟用使用者及文件標籤補顯示值。
4. 以頁碼查看完整期間，月報盤點時保留查詢區間、Page／PageSize 與查詢時間。
5. `Page <= 0` 會轉為第一頁偏移量；查無紀錄時接受空集合，不補造紀錄。

## 3. 查看單筆明細

1. 從清單取得目標紀錄 `id`，確認不是文件 ID 或其他識別值。
2. 呼叫 `GET api/DocumentQaRecord/QueryAiDocAskRecordDetail?id=...`。
3. 依回傳的 `DocInfos` 與 `AiRecordInfos` 對照文件與 AI 對話資訊；這是後端分組後的顯示結構。
4. 若紀錄不存在，保留查詢 id、帳號與時間，勿用其他紀錄代替。

## 4. 欄位、狀態與例外

| 項目 | 維運重點 |
|---|---|
| 日期／文件條件 | 由 `QueryDocumentQaRecordsRq` 傳入；月報應記錄實際查詢期間。 |
| `Page`／`PageSize` | 清單分頁欄位；`Page <= 0` 時 offset 按 0 處理。 |
| `CreatedName` | 由啟用使用者清單補值；找不到對應人員時可能回退 `CreatedBy` 數字。 |
| `TagName` | 由文件標籤清單補值；找不到對應標籤時可能為空字串。 |
| 明細 `id` | `QueryAiDocAskRecordDetail` 的單筆紀錄識別。 |
| 資料狀態 | 查詢不改變狀態，不會觸發重新問答或向量同步。 |

## 5. 異常處理與排錯

| 情況 | 先檢查 | 處理方式 |
|---|---|---|
| 月報筆數為 0 | 日期區間、文件／標籤條件、分頁與環境 | 重新確認查詢條件；空集合是正常回應，不自行補資料。 |
| 建立者或標籤顯示不完整 | 啟用使用者／標籤查詢結果與原始 CreatedBy／TagId | 保留原始識別值與時間，交維運確認對照資料；不要手動改寫紀錄。 |
| 明細為空 | `id` 是否為問答紀錄 id、紀錄是否仍存在 | 重新從清單取得 id；底層回空結構時不要以相鄰紀錄替代。 |
| API 或 MariaDB 查詢失敗 | endpoint、帳號、時間、request id 與資料庫錯誤 | 兩個 endpoint 沒有額外 try/catch，保留底層錯誤交系統／資料庫維運。 |
