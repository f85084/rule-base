# 優質音檔

本篇是 CSP／MI 的優質音檔管理入口，對應網站路由 `/AudioShared`。用於查詢、播放、編輯與刪除已分享至優質音檔區的音檔；音檔建立與剪輯主要從[調聽音檔](22-調聽音檔.md)進入。

## 權限與使用前確認

- 具有優質音檔功能權限者可查詢與收聽被分享的音檔；編輯與刪除限分享者或管理權限。
- 音檔分享、個人存放區及部分儲存按鈕曾依版本調整為管理權限；目前是否顯示【儲存】、【分享】、【刪除】以帳號在調聽音檔頁面的角色與目前部署版本為準，不要以舊手冊推定一般帳號可異動。
- 開始操作前確認音檔用途、分享者、Connection ID、音檔編號與是否包含個資或不適合公開的內容。

## 查詢與播放

1. 進入【優質音檔】，搜尋類型目前預設為【音檔位置】；依畫面可用條件選擇音檔位置、音檔編號，或以音檔名稱／說明輸入關鍵字。
2. 名稱與說明可使用兩個關鍵字查詢，例如專員與商品名；查詢前先確認關鍵字與目前搜尋類型。
3. 列表至少核對音檔編號、音檔名稱、音檔說明、分享者、分享日期及 Connection ID，再點播放 icon。
4. 播放前確認選到的音檔與案件或教學用途相符；播放異常時保留音檔編號、Connection ID、分享者與時間。

## 建立分享音檔

建立與剪輯通常從【調聽音檔】或預覽播放清單進入：

1. 選擇要分享的音檔，確認音檔與 Connection ID。
2. 輸入音檔名稱、選擇儲存位置，填寫音檔說明；需求單記載說明上限調整為 300 字。需要便於銷編搜尋時，依現行欄位格式填寫銷編／內容註明。
3. 如只分享部分內容，設定【關鍵時刻】的開始與結束時間；未設定時分享整段音檔。
4. 送出前確認剪輯區間沒有包含不應分享的個資或敏感內容，再完成分享並回到優質音檔列表查詢。

## 編輯與刪除

- 編輯可調整音檔名稱、儲存位置、音檔說明及其他頁面允許欄位。已分享音檔的【關鍵時刻】依來源規則不可直接修改；若需重新剪輯，回到調聽音檔建立新的分享版本。
- 刪除前確認分享者、音檔編號及是否仍被質檢、教育或其他案件引用；刪除會留下 Log，不能以重新查詢還原資料。
- 刪除按鈕僅在符合管理權限／頁面權限時顯示。若一般帳號看不到，不要以 UI 缺少按鈕判定資料異常。

## 常見異常

| 現象 | 先檢查 | 處理方式 |
|---|---|---|
| 查不到音檔 | 搜尋類型、音檔位置、編號、名稱／說明關鍵字與權限 | 先用音檔編號或 Connection ID 查詢，再保存條件與結果 |
| 找到資料但無法播放 | 音檔編號、實體檔案狀態、播放器與目前權限 | 重新開啟播放並記錄發生時間；必要時回到[調聽音檔](22-調聽音檔.md)比對來源音檔 |
| 分享或儲存按鈕不見 | 調聽音檔角色、目前版本、帳號權限 | 依近期權限調整確認是否應為管理權限；不要用其他帳號代操作 |
| 說明欄位送出失敗 | 字數、特殊內容、欄位是否為目前版本要求 | 依 300 字限制縮短內容並重新確認；保留錯誤提示 |
| 關鍵時刻無法修改 | 音檔是否已分享至優質音檔 | 回調聽音檔重新剪輯，不要反覆嘗試修改既有分享版本 |
| 刪除後仍看到資料或誤刪多筆 | 音檔編號、刪除 Log、列表快取與批次勾選 | 先停止後續刪除，保存音檔編號、操作人與時間，交維運核對 Log |
