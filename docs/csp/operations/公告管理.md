# 公告管理

本頁給管理職與維運人員查詢、新增、編輯、置頂、郵寄及刪除 MI 公告使用。網站路由為 `/Announcement`。

## 1. 查詢公告

1. 進入【公告管理】。
2. 依公告類型、公告主題或公告人查詢；公告人使用組織圖指定人員。
3. 公告主題查詢不可超過 20 字。
4. 首頁列表每頁顯示 15 筆；管理頁列表每頁顯示 10 筆。
5. 置頂公告會顯示在最上方，其餘通常依最後修改日期由新到舊排列。
6. 只會顯示目前在公告起迄日期內的公告。

查詢結果先確認公告類型、主題、公告人、公告日期與最後修改資訊，再開啟公告內容。

## 2. 新增公告

新增前先確認公告對象、公告期間與公告類型，再依序填寫：

1. 選擇公告類型。
2. 輸入公告主題；目前手冊記載上限為 60 字。
3. 設定公告起日與迄日；起日不可早於今天。
4. 輸入公告內容，可設定文字大小、顏色、表格與圖片。
5. 需要置頂時勾選【置頂】，再確認置頂取消日期。
6. 儲存前檢查預覽內容、公告期間與收件／顯示範圍。
7. 點選【確定】完成新增；點選【取消】則放棄此次設定。

若未填寫公告日期，來源手冊記載起日預設為當日、迄日預設為 `2099/12/31`。新增後建立時間會同步成最後修改日期，公告人會同步成最後修改人。

## 3. 置頂與期間

- 置頂預設不勾選；勾選後才會顯示置頂取消日期。
- 置頂取消日期預設為一個月後。
- 取消日期到期後，系統會自動取消置頂。
- 修改公告期間時，確認新起迄日期仍符合公告目的，避免公告尚未生效或過期後仍被期待顯示。

## 4. 編輯、郵寄與刪除

### 編輯

開啟公告後修改內容或期間，儲存後回到列表確認最後修改人與日期已更新。涉及公告文字、連結或圖片時，重新開啟公告檢查實際顯示結果。

### 郵寄

公告管理頁提供【郵寄】功能時，可將公告內容打包成 `.eml` 檔案下載，再依組織的 Mail 流程寄送。下載前先確認公告版本、收件對象與內容不含不應外寄的資料。

### 刪除

刪除前確認公告是否已對外顯示、是否仍需保留歷程或作為維運紀錄。若只是暫停顯示，優先調整公告期間或取消置頂，不要直接刪除。

## 5. 內容與圖片限制

- 公告主題不要輸入 `<`、`>` 等特殊字元，避免送出時無反應。
- 完整手冊記載公告內容上限為 8,000 字，且表格／圖片轉換可能造成字元數膨脹。
- 需求單 [#48686](https://redmine.etzone.net/issues/48686) 的標題記載內容上限提高至 15,000 字；實際上限需依目前部署版本驗證，不能只依手冊的 8,000 字判斷。
- 編輯器可插入表格與圖片；若字數異常增加，先刪減複雜表格或改用圖片截圖後再送出。
- 小於等於 960 像素的圖片不會被放大；上傳檔案會放在文章底部，使用者可點選下載或另開閱讀。

## 6. 常見異常

| 現象 | 先確認 |
|---|---|
| 查不到公告 | 公告類型、主題字數、公告人、公告期間與目前帳號範圍。 |
| 公告送出沒有反應 | 主題特殊字元、內容字數、表格／圖片轉換與必填欄位。 |
| 公告沒有置頂 | 是否勾選置頂、置頂取消日期是否已到期。 |
| 公告仍顯示或不顯示 | 起迄日期、時區、頁面快取與公告是否已儲存。 |
| 圖片破圖或轉圈 | 圖片格式、內容轉換、檔案是否成功上傳與公告版本。 |
