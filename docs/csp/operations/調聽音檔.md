# 調聽音檔

本頁給管理職與維運人員查詢、播放、保存及分享客服進線／外撥音檔使用。網站路由為 `/AudioLog`。

## 1. 權限與功能區

音檔管理包含三個主要區塊：

- 【調聽音檔】：查詢音檔、加入播放清單與播放。
- 【個人存放區】：保存自己後續需要查閱的音檔，可編輯說明並管理自己的檔案。
- 【優質音檔】：剪輯並分享給有權限的專員收聽。

一般權限可查詢、聽音檔、保存至個人存放區及分享優質音檔；管理權限另可設定音檔目錄。實際可用功能仍以帳號在調聽音檔頁面的角色權限為準。

## 2. 查詢音檔

可依下列條件查詢：

- 專員姓名、專員編號、專員席位。
- 外撥／進線電話。
- 關聯單號（lab區 2020-02-26 以後的訂單）。
- 音檔編號、客戶編號、Connection ID。

操作時建議先使用最可靠的識別值（例如 Connection ID 或關聯單號），再用日期、專員或電話縮小範圍。線上資料量較大時，查詢範圍與資料更新速度可能受系統設定限制；目前手冊記載查詢範圍為兩天、音檔約每 30 分鐘更新一次，若現場行為不同應以目前版本驗證。

若音檔有串接市話或手機，可使用客戶查詢圖示帶入【客戶查詢】；沒有串接電話資料時，該連結可能顯示查詢失敗。

## 3. 播放音檔

1. 在查詢結果選擇要處理的音檔，加入播放清單。
2. 開啟 MI 調聽音檔播放器播放。
3. 依需要使用播放、暫停、快轉 10 秒、倒退 10 秒與播放速度控制。
4. 播放前確認音檔編號、Connection ID、專員與聯繫方式相符。

若音檔沒有結束時間，播放清單長度可能顯示 `00:00`，不代表一定沒有音檔；需實際嘗試播放並檢查檔案狀態。

## 4. 加入、保存與刪除

### 播放清單

從調聽列表加入音檔後，可在播放清單集中播放。若從【聯繫歷史】加入音檔，Connection ID 後方會出現加入／移除音檔的操作狀態。

### 個人存放區

1. 在音檔列表選擇【儲存至個人存放區】。
2. 確認音檔名稱、說明與存放位置。
3. 儲存後系統會產生音檔編號，可在個人存放區編輯說明。
4. 刪除時只處理自己保存的音檔，並確認刪除 Log 已留下。

原始測試資料另記載過期音檔標示與刪除全部過期音檔功能；實際刪除前先確認是否仍有案件、質檢或教育用途引用。

### 優質音檔

1. 選擇【儲存至優質音檔】。
2. 輸入音檔名稱、說明、存放根目錄與必要的銷編。
3. 需要剪輯時設定開始與結束時間；未設定時間時分享整段音檔。
4. 分享後由具備功能權限的專員查詢與收聽。

分享音檔的「關鍵時刻」一旦建立，後續編輯可能不可修改；若需調整，先確認是否要重新建立分享版本。刪除優質音檔通常限分享者或管理權限，並會記錄刪除 Log。

## 5. 音檔目錄與發信號碼

音檔目錄的新增、修改與刪除受管理權限限制。刪除含有音檔的資料夾前，先確認系統提示與資料範圍，避免連同仍需保存的音檔一併移除。

調聽列表的發信號碼會依會員等級與換號規則顯示新號或舊號；若欄位為空，可能不顯示。需要核對外撥號碼時，應同時比對外撥方式、會員等級、外撥日期與音檔紀錄。

## 6. 音檔找不到或無法播放

| 現象 | 建議檢查 |
|---|---|
| 查不到音檔 | 先確認 Connection ID、日期範圍、專員／電話條件與帳號權限。 |
| 查到資料但播放失敗 | 比對索引建立時間、音檔實際建立時間與檔案是否已生成。 |
| 音檔稍後又可以播放 | 可能是索引已建立但 NAS 實體檔案尚未生成，等待後重試。 |
| 客戶查詢連結失敗 | 確認音檔是否有串接市話或手機。 |
| 播放清單資料異常 | 重新整理並重新加入音檔，記錄 Connection ID、發生時間與畫面訊息。 |

索引與實體音檔可能有時間落差，詳細案例請看[音檔索引延遲排錯](../troubleshooting/audio-index-delay.md)。不要只因第一次播放失敗就直接判定權限或路徑錯誤。

## 7. Lab 測試

Lab 的連線方式與測試 Connection ID 保留在[調聽音檔測試資料](../test-data/test-data-audio-log.md)。基本驗證流程：

1. 從 MI 查詢或加入測試音檔。
2. 加入播放清單並重新整理。
3. 確認音檔出現後播放，記錄查詢條件與結果。
4. 需要排查時，比對 API 回應、索引時間與實體檔案狀態。

原始文件含有受控登入資訊，本頁不重複記錄帳號、密碼、主機登入資訊或連線字串。
