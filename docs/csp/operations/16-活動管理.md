# 活動管理

本頁給維運人員查詢與處理客戶活動相關功能使用。網站路由為 `/Activity`；目前需求內容包含限量品登記、活動提示、直播／見面會統計、藍鑽與小額奪寶等歷史功能，實際畫面依帳號權限與目前啟用模組顯示。

## 1. 先確認活動模組

進入活動管理後，先確認目前要處理的功能與客戶資料：

1. 確認客代、客戶姓名與目前活動名稱。
2. 確認目前功能是限量品登記、活動查詢、直播／見面會、藍鑽或小額奪寶。
3. 先閱讀頁面提示與活動期間，再執行新增、修改、刪除或投注操作。
4. 涉及名單、部門或客戶資格時，確認目前帳號的可見範圍與活動條件。

活動管理的需求跨越多個歷史模組；若畫面中找不到對應功能，先確認模組是否仍啟用，不要直接將功能判定為資料遺失。

## 2. 限量品登記

限量品登記是目前活動管理需求中需求量較高的一組功能。處理時：

1. 先依商品、活動或部門條件查詢登記資料。
2. 核對登記對象、活動條件、登記時間與目前名額／狀態。
3. 新增或調整登記前，確認客戶資格與活動規則，並閱讀畫面提示。
4. 刪除或取消登記前，確認是否已產生後續訂單、通知或其他紀錄。
5. 完成後重新查詢，確認資料已更新且沒有重複登記。

需求單曾針對部門搜尋、按鈕位置、提示文字與刪除流程調整；若實際操作與文件描述不一致，應記錄畫面版本、活動名稱與發生時間。

## 3. 小額奪寶與點數活動

完整手冊記載小額奪寶使用 E 幣投注，作為 E 幣使用途徑。操作前：

- 確認目前客戶與可用 E 幣資料。
- 確認活動仍在有效期間，並閱讀投注規則與提示。
- 送出前核對投注選項與扣除金額。
- 完成後回查投注紀錄與餘額；若畫面提示失敗，不要重複送出造成重複扣款。

藍鑽活動已在手冊標示自 2024-09-01 起停止累點；若舊畫面仍顯示藍鑽欄位，先依目前公告與版本確認，不要向客戶承諾仍可累點。

## 4. 直播／見面會活動

直播活動需先確認直播類型：

- Google Meet：封閉式視訊，只有收到連結且符合條件的客戶可參與。
- YouTube：開放式視訊，以觀看為主，無法與客戶互動。

活動通知通常會在開始前 10 分鐘透過簡訊／LINE 推播發送連結。報名或通知前確認：

1. 客戶是否同意接收活動通知。
2. 客戶是否已綁定或封鎖東森購樂趣 LINE。
3. 客戶是否有可用手機號碼。
4. 活動連結、開始時間與報名資料是否正確。

若客戶未綁定／封鎖 LINE，系統可能顯示簡訊建議；若沒有手機號碼，會提示無法發送簡訊。直播結束後依活動流程發送感謝訊息與後續推薦內容。

直播報名名單與統計請依[直播報名管理需求](../requirements/pages/18-直播-見面會報名.md)及目前對應頁面查閱；本頁只記錄活動管理的共通判斷。

## 5. 行事曆與活動提醒

行事曆是另一個活動入口，整合課程、名單、直播、活動、商品與維運項目：

- 一般使用者通常只能查看自己單位的項目。
- 管理職可依權限新增、修改、刪除活動與管理標籤。
- 活動同日通常依時間，再依課程、名單、直播、活動、商品、維運、其他排序。
- 隔日有活動時，登入可能顯示行事曆紅點；點開後通知會消失。
- 行事曆活動可設定網址，點擊活動名稱開啟外部頁面。

詳細的行事曆管理請看[內部工作管理](內部工作管理.md)與[行事曆管理需求](../requirements/pages/39-行事曆管理.md)。

## 6. 異常與交接

| 現象 | 先確認 |
|---|---|
| 查不到活動或登記資料 | 客代、活動期間、部門／權限與功能模組是否正確。 |
| 登記結果沒有更新 | 重新查詢、確認送出提示與是否有重複或資格限制。 |
| 刪除前後資料不一致 | 是否已產生訂單、通知或其他關聯紀錄；保留活動名稱與登記對象。 |
| 直播通知未送出 | LINE 綁定／封鎖狀態、手機號碼、活動開始時間與通知排程。 |
| E 幣投注結果不明 | 先查投注紀錄與餘額，再決定是否回報，不要直接重送。 |

需要轉交商品、活動、行銷或客服單位時，至少記錄客代、活動名稱、功能頁、操作時間、畫面提示與目前資料狀態。
