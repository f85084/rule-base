# 直播／見面會報名

本篇是 CSP／MI 的直播／見面會報名入口，對應網站路由 `/LiveStreamSignUp`。本頁供專員查看可報名與歷史報名場次、替客戶送出或取消報名；場次建立、編輯、簡訊與完整名單管理屬管理端流程。

## 權限與分頁

- 【可報名場次】供一般權限使用者選擇場次並完成報名；【歷史報名場次】查看客戶曾報名的已過期或已取消場次。
- 一般權限只能查看自己處別／組別的報名名單；管理權限可查看全部報名名單，並依頁面權限編輯與下載。
- 管理端新增場次、編輯場次及發送簡訊僅限管理權限；本入口不代替 `/LiveStreamManage` 的管理操作。

## 報名前確認

1. 先確認目前客戶、客代與可使用的手機、LINE／Meet／YouTube 帳號資料。
2. 在可報名場次核對活動時間、活動名稱、廠商、主持人、嘉賓、活動狀態、直播類型、場次人數與已報名人數。
3. 場次狀態為延期時，依頁面紅字／紅底提醒重新確認時間；取消場次不可再報名。活動時間已過或報名時間已過的場次不應繼續送出。
4. 直播類型需分辨：Google Meet 為封閉式視訊，需客戶同意接收連結；YouTube 為開放式觀看，無法與客戶互動；來源需求另列有 Line 類型，依場次設定使用對應帳號。

## 送出或取消報名

1. 勾選可報名場次，填寫頁面允許的客戶欄位：客戶稱謂、Meet／Line／YouTube 帳號名稱、Gmail 信箱等。
2. 依目前報名介面填寫互動意願與發問。兩欄可分開處理；互動意願與發問不是都必填，欄位是否可輸入以頁面狀態為準。
3. 點【報名】後確認彈窗內容，再完成送出；不要因為未填非必填欄位而重複點擊。
4. 取消報名時點【取消】並確認提示；選【確定】才取消，選【取消】則留在原報名頁面。
5. 完成後到歷史報名場次或目前清單回查狀態、活動名稱、場次狀態與報名資料。

## 通知與登入資料

- Google Meet 直播需客戶同意接收活動通知與入場連結；活動開始前約 10 分鐘，系統可能透過簡訊／LINE 推播發送連結。
- 報名成功時若客戶未綁定或封鎖東森購樂趣 LINE，頁面可能顯示未綁定／疑似封鎖提示及簡訊建議；先依客戶意願確認是否補用簡訊。
- 客戶沒有手機號碼時，頁面會提示「客未留手機號碼，無法發送簡訊，請重新確認！」；補齊資料前不要承諾通知一定已送出。
- 報名明細中的部、處、組應以目前組織資料顯示；若出現過於概括的事業部名稱，保留場次與名單資料回報。

## 報名明細與歷史

- 點場次的【瀏覽】可進入報名明細頁；管理權限依頁面可編輯客戶稱謂、帳號名稱、信箱、互動意願與發問，並下載 Excel。回上頁應保留原搜尋結果。
- 報名現況可由已報名人數開啟，依處統計顯示各處報名數；此數字用於查看現況，不應自行當作報名上限判斷。
- 場次取消但客戶已報名時，仍應在歷史報名場次保留紀錄並顯示活動狀態，供專員確認是否需要聯絡客戶。

## 常見異常

| 現象 | 先檢查 | 處理方式 |
|---|---|---|
| 找不到可報名場次 | 場次時間、狀態、客戶權限、是否已過報名時間 | 切換歷史分頁確認；不要對已取消或已過期場次重送 |
| 報名送出後沒有成功 | 客戶資料、互動／發問欄位、場次狀態與網路回應 | 先回查是否已產生報名紀錄，再決定是否重試，避免重複報名 |
| LINE 報名異常 | 是否綁定／封鎖 LINE、場次直播類型與帳號名稱 | 記錄提示文字、客代、場次與時間；依頁面提供的簡訊建議處理 |
| 沒有手機號碼 | 客戶手機欄位、通知方式 | 向客戶確認手機後再處理；保留無手機提示，不要把簡訊視為已送出 |
| 報名明細組織顯示錯誤 | 部／處／組欄位、登入權限、場次 | 記錄顯示值與預期組織，回報組織資料或頁面問題 |
| 取消場次仍有客戶報名 | 活動狀態、歷史分頁、報名時間 | 以歷史報名紀錄為準，確認是否需要聯絡客戶；不要刪除歷史資料 |
| 報名人數與處統計不一致 | 場次、統計時間、處別範圍與是否重複報名 | 保存場次 ID、畫面筆數與查詢時間，交管理端比對 |
