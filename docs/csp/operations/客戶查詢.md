# 客戶查詢

## 查詢與判讀

可用客代、姓名、手機、生日、會員等級、OB 會員等級、郵遞區號等條件查詢。從 TM 名單點選客戶編號，也可直接帶入客戶查詢頁。

查到客戶後，先核對姓名、客代、手機與目前作業客戶，再進行接單、簡訊、客訴或資料異動。

## 客戶資訊

- 訂單清單：查看消費紀錄。
- 外撥交談註記：查看歷次聯繫內容。
- 消費者輪廓 SCV：查看累計、近一年／三年消費與通常進線時間。
- 客戶備註：查看方便聯繫時間與特殊飲食等常態資訊。
- 360 畫像、人物誌：查看消費、偏好、標籤與摘要。
- 問卷：查看尚未完成的問卷。

交談註記只記錄工作需要的聯繫資訊，不記錄病史、政治或個人負面觀感。
