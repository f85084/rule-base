# 聯繫歷史

## 一般人員操作入口

**這頁做什麼**：在 `/ContactHistory` 查詢客戶的進線、外撥、簡訊、Email、郵寄、傳真、APP 推播與 OB LINE 等聯繫紀錄。可從客戶查詢帶入客代，也可依授權直接查。

**開始前**：準備客代、日期起迄、聯繫方式或關鍵字；沒有客代時先確認時間條件與接洽人員，避免查到過大範圍。

**照著做**：

1. 開啟聯繫歷史，輸入客代或日期／人員／聯繫方式條件，按【查詢】。預期結果：列表符合目前查詢條件。
2. 逐筆核對日期、聯繫方式、操作者、內容與 Connection ID；需要音檔時再交有權限人員調聽。預期結果：不把不同來源紀錄混成一筆。
3. 依畫面提供的入口重新發送、下載或加入播放清單前，核對客戶與內容。預期結果：副作用與目標可追溯。

**完成確認與常見問題**：查詢條件、列表／明細與後續檔案符合需求。空結果先縮小／放寬日期與客代條件；單一聯繫方式缺資料時記錄來源與時間，不判定整頁故障。

**影響與技術附錄**：重新發送、下載與播放清單會產生操作或資料保存副作用；資料合併、API 與媒體來源留在後段。

## 1. 用途、入口與權限視角

聯繫歷史用來查詢客戶過去的客服進線、語音、外撥、簡訊、電子郵件、郵寄、傳真、APP 推播與 OB LINE 等互動紀錄。現行前端 route 為 `/ContactHistory`，可從客戶查詢帶入客代；該 route 設定為可不先綁定客戶的查詢入口。

一般專員的「被指定人」通常是目前登入者；具管理權限者可依畫面選擇其他專員或使用音檔播放清單。重新發送與音檔操作會受資料類型與帳號權限限制，完整矩陣以當期 UI／後端授權為準。

## 2. 正常查詢流程

1. 由客戶查詢帶入客代，或直接開啟 `/ContactHistory`。
2. 選擇被指定人、聯繫日期起訖與聯繫方式；選簡訊時才輸入關鍵字。
3. 點選【查詢】，確認總筆數、頁碼與條件仍保留。
4. 由結果的聯繫方式、媒體通路、日期時間、接洽人員、CTI／小結與 Connection ID 判讀紀錄。
5. 需要重送簡訊／電子郵件、下載文件或加入音檔時，先核對該列客代、聯絡目的地與資料類型，再使用相應按鈕。

## 3. 查詢條件與欄位

- 指定客代時，查詢該客戶所有聯繫歷史；接洽人員條件不生效，其他欄位可不填。
- 未指定客代但指定人員時，可查該人員資料；未指定客代且未指定人員時，至少填起日或迄日，通常限制單日。
- 迄日不可早於起日；簡訊關鍵字不可輸入空白。若只輸入一側日期，系統依目前表單規則組合查詢條件。
- 聯繫方式包含客服／語音連線、客服外撥、電子郵件、簡訊、郵寄、傳真、APP 推播與 OB LINE 等，實際選項以當期下拉選單為準。
- Connection ID 是電話外撥／進線音檔的關聯識別；CTI 位置可查看電話結束時的小結資訊。電話號碼輸出可能遮罩，不要以遮罩字串當成完整號碼。

## 4. 資料來源與合併方式

- 查詢列表由聯繫歷史查詢結果提供；列上的媒體通路會依聯繫方式與相關資料組合顯示，例如郵件主旨、郵寄備註／文件名稱或簡訊內容摘要。
- 郵寄、電子郵件與其他文件下載可能另查文件資料；文件內容、列表資料與聯繫主檔是不同來源，單一下載失敗不代表歷史不存在。
- Connection ID 對應音檔或播放清單資料；只有具備資料與權限時才會顯示可用操作。列表、文件、音檔要以各自識別值合併，不要用顯示文字比對。
- 分頁切換會依原查詢條件重新查詢；若條件被清除，先回第一頁重查再比較筆數。

## 5. 寫入與副作用

- 【重新發送】會再次對原目的地發送簡訊或電子郵件，是對外副作用；送出前核對聯絡方式、收件資料與原內容。
- 【下載】只取得文件／郵件內容，不等於重新發送。
- 【加入音檔】會把符合條件的 Connection ID 加入管理職可用的預覽播放清單；加入後會顯示【移除音檔】。播放清單變更不會改寫聯繫歷史主檔。

## 6. 空資料、部分失敗與錯誤排查

| 現象 | 先檢查 | 判讀與處理 |
|---|---|---|
| 完全無法查詢 | 登入、被指定人、日期與共用服務 | 先判斷頁面／權限問題，保留錯誤訊息。 |
| 結果為空 | 客代優先規則、指定人、日期單日限制、聯繫方式與關鍵字 | 以客代或單日條件重查；空結果不代表沒有所有聯繫紀錄。 |
| 簡訊查詢不能送出 | 關鍵字是否含空白、日期與聯繫方式 | 移除空白並確認日期；不要直接改 API 參數繞過驗證。 |
| 列表有資料但媒體通路／文件空白 | 聯繫類型、文件識別、來源同步 | 視為單一來源或尚未同步，保留聯繫識別值。 |
| 重新發送失敗或結果不明 | contact ID、目的地、API 回應與聯繫歷史 | 不要重複點擊；先確認是否已送出，再交維運查核。 |
| Connection ID 無音檔／無法加入 | 聯繫類型、ID、帳號權限與播放清單 | 僅客服進線／外撥且有資料時處理，其他類型可能沒有音檔。 |
