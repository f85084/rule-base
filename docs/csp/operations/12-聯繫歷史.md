# 聯繫歷史

## 查詢規則

- 指定客代：查詢該客戶所有聯繫歷史，接洽人員條件不生效。
- 未指定客代但指定人員：可查該人員資料。
- 客代與人員都未指定：至少輸入起日或迄日，且通常限制單日查詢。
- 迄日不可早於起日；簡訊關鍵字不可輸入空白。

可依客服／語音連線、客服外撥、電子郵件、簡訊、郵寄、傳真、APP 推播、OB LINE 等聯繫方式篩選。

## 其他操作

- 可重新發送已發送的簡訊或電子郵件。
- Connection ID 可供管理職調聽外撥／進線音檔。
- 管理權限可將符合條件的 Connection ID 加入播放清單。
