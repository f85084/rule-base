# 電話小結作業

## 一般人員操作入口

**這頁做什麼**：在通話結束後於 `/CallSummary` 選擇實際結果、追蹤狀態、重新安排與關聯訂單。待處理小結也可從右上角小鈴鐺開啟。

**開始前**：先確認通話對象、客代、專案／名單與本次實際結果；待處理小結有時間界線，找不到時不要自行補建另一筆。

**照著做**：

1. 從小鈴鐺或【電話小結進入】開啟待處理清單，核對客戶與通話時間。預期結果：選到本次通話的小結卡片。
2. 依實際結果選成交、失敗、未成交、指定回電、拒絕或其他服務等狀態，填畫面要求的欄位。預期結果：表單驗證通過。
3. 需要再聯繫時設定【重新安排】日期／時間；需要關聯訂單時先核對商品／客代。預期結果：追蹤資訊與訂單關聯正確。
4. 送出後回清單或 TM 名單確認小結完成。預期結果：待處理項目不再以未完成狀態出現，或畫面明確提示下一步。

**完成確認與常見問題**：客戶、結果、追蹤狀態與時間可回查。清單全空先區分逾時／未接來電與頁面故障；送出失敗保留欄位與時間，不重複建立小結。

**影響與技術附錄**：小結會影響名單、通知、預約與後續訂單關聯；資料合併、API 與時間邊界留在後段。

## 1. 用途、入口與權限視角

電話小結用來在通話結束後記錄聯繫結果、推薦／服務處理、追蹤狀態、預約外撥與關聯訂單。現行前端 route 為 `/CallSummary`；未完成的小結也可由右上角通知直接開啟。

待處理小結主要由產生該通話的客服人員處理；其他角色是否可查看或處理，依當期登入權限與通知內容為準（**runtime 未確認**）。電話號碼在清單上會遮罩顯示。

## 2. 正常操作流程

1. 通話結束後從小鈴鐺或功能選單【電話小結進入】開啟待處理清單。
2. 依客戶、客代、專案標籤與時間辨識目標小結，點卡片開啟表單。
3. 先選擇通話結果：電聯成功商品推薦、電聯成功服務處理或電聯失敗；再填寫畫面依結果展開的必填欄位。
4. 填寫追蹤狀態；若要回電，設定【預約外撥】日期／時間。
5. 需要關聯訂單時填單號與項次；有訂單快取時先核對系統代入值，不正確就修正。
6. 按【完成】一次送出，確認成功提示後回查待處理清單與 TM 名單，確認該筆已移除或標籤更新。

## 3. 欄位、狀態與限制

- 追蹤狀態是必填；可用選項與排序依當期資料設定，不能只依舊截圖判斷。
- 主力商品成交與會員卡銷售等欄位可能在選擇成功流程後展開，畫面標示紅色星號的欄位必須完成。
- 關聯訂單的項次在填寫單號時必填；若不填關聯單號，項次不需填寫。來源手冊記載預設項次為 1、預設關聯商品多重碼 84，仍可由使用者修改。
- 若通路選「OB 衛購」，頻道必須選擇；未選會提示「OB 衛購通路頻道未選擇」。
- 富購查不到關聯單號時會提示「查無此單號」；不能以不存在的單號完成小結。
- 待處理電話小結只保留約 1 小時；未接來電會略過小結。這是來源手冊與需求紀錄的規則，當期保存行為仍屬 runtime 未確認。

## 4. 資料來源與合併

- 頁面先取得小結選項／樹狀資料與未完成清單；點選客戶後另查關聯訂單快取與推薦標籤。
- 小結卡片以小結識別值為主鍵，客代用來載入訂單與會員上下文；不要用電話或姓名合併不同小結。
- 完成表單會將追蹤狀態、通路／頻道、關聯訂單、描述與推薦結果一起送出；頁面列表刷新與 TM 名單更新可能是不同反應來源。
- 清單載入成功但某筆訂單或推薦資料失敗，先視為單一資料區塊問題；不要直接重建小結。

## 5. 寫入與副作用

- 【完成】會寫入電話小結及相關聯繫／推薦資料，成功後從待處理列表移除或刷新。
- 設定【預約外撥】會把時間帶入 TM 名單；來源手冊記載預約時間前約 30 分鐘通知，實際通知仍以當期系統為準。
- 未完成小結時，系統可能阻擋再次外撥並提示先完成小結；未接來電則依規則不建立待處理小結。
- 完成後 TM 搜尋與標籤篩選通常會保留，不代表所有通知或下游名單 API 已同步；需回查實際畫面。

## 6. 空資料、部分失敗與錯誤排查

| 現象 | 先檢查 | 判讀與處理 |
|---|---|---|
| 頁面無法開啟或清單全空 | 登入、通知、共用服務與當前時間 | 先區分頁面故障與 1 小時逾時／未接來電規則。 |
| 點通知找不到小結 | reference ID、清單刷新時間、是否已完成或逾時 | 重新載入清單；保留通知時間與識別值。 |
| 完成按鈕無法送出 | 追蹤狀態、星號必填、關聯單號／項次、OB 頻道 | 依表單提示補齊；不要重複點擊。 |
| 顯示查無此單號 | 關聯單號、項次與訂單來源 | 修正為可查訂單，或清除關聯單號後依規則送出。 |
| 完成成功但 TM／通知未更新 | 小結回應、列表刷新、客代與 SignalR／通知時間 | 分開確認小結寫入與下游同步，不要重做同一通小結。 |
| 未完成小結阻擋外撥 | 是否真的仍有未結小結、是否為未接來電、建立時間 | 先回小結頁完成或確認逾時，再重新外撥。 |
