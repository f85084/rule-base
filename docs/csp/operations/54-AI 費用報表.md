# AI 費用報表

## 敘述狀態與查核界線

- **現行事實**：本頁正文依目前列出的頁面用途、操作流程與來源整理。
- **runtime 未確認**：未在目前環境實際驗證的角色按鈕、API 回應、資料同步、保存期限與版本差異，不視為目前保證；以當期 UI、API 與授權設定為準。

本篇是 CSP `/AiCostReport` AI 費用報表與模型計費設定入口。頁面分為費用查詢／Excel 匯出，以及管理員才可見的 AI 模型成本維護；報表上的成本會依目前模型設定於查詢時重算，不一定等於資料庫原始欄位。

## 1. 權限與資料邊界

- 登入後可查詢下拉選項、費用清單、模型清單與下載報表；AI 模型新增、修改、刪除需要管理權限，實際按鈕以目前帳號為準。
- 查詢／匯出是讀取流程，不直接修改費用紀錄；模型成本維護會影響後續查詢與匯出的成本重算。
- 查詢與匯出條件可以相同，但兩者是不同 API；不要以列表畫面已更新推定下載檔已成功產出。

## 2. 載入條件與費用查詢

1. 開啟 `/AiCostReport`，頁面先呼叫 `GET api/AiCostReport/QueryDropdownOptions` 載入 PromptTypes、ServiceTypes。
2. 頁面再呼叫 `POST api/AiCostReport/QueryAiModelList` 載入目前模型清單；查無資料時為空集合。
3. 確認查詢條件：`ServiceType`、`AiModel`、`PromptType`、`StartDate`、`EndDate` 都可選；頁面預設最近 14 天，實際以畫面目前值為準。
4. 執行 `POST api/AiCostReport/QueryList`，以 `Page`、`Limit` 分頁查看明細與總筆數。
5. 若有 `EndDate`，後端會將結束時間展開至該日 23:59:59；核對跨日數字時不要把截止日誤當成當日 00:00 結束。
6. 報表成本由查詢回模型設定後，在記憶體內重算 `TotalRequestCost` 與 `TotalResponseCost`；記錄查詢時使用的模型設定與時間範圍。

## 3. 下載報表

1. 先確認列表條件與資料範圍，再執行 `POST api/AiCostReport/DownloadCostReport`。
2. 匯出流程會依相同模型成本設定重算資料，套用 Excel 範本後回傳下載檔。
3. 成功檔名格式為 `AI費用報表_yyyy-MM-dd_HHmmss.xlsx`；下載後檢查檔案可開啟、條件與總筆數是否符合需求。
4. 空結果仍可能產出帶範本格式的 Excel；不要把「有檔案」當成「有費用資料」。

## 4. AI 模型成本維護

1. 以管理權限開啟模型維護，先用 `POST api/AiCostReport/QueryAiModelList` 取得目前清單。
2. 新增／修改時確認 `Service`、`Model`、`TokenCount`、`RequestCost`、`ResponseCost`；目前登入者 UserId 由後端注入。
3. 儲存使用 `POST api/AiCostReport/CreateOrUpdateAiModel`。後端以不分大小寫的 `Service + Model` 判斷既有資料：存在則更新，不存在則新增。
4. 刪除使用 `POST api/AiCostReport/DeleteAiModel`，以 `Service + Model` 定位；刪除前確認該模型是否仍是費用重算所需設定。
5. 儲存／刪除後重新查詢模型清單與費用報表，確認後續成本重算使用的是預期設定。

## 維運查核補充

以下欄位、API、模型成本與驗證對照只供維運查核；一般讀者先依前文完成條件、列表或模型維護操作。

| 操作／欄位 | 規則／例外 |
|---|---|
| `QueryDropdownOptions` | `GET api/AiCostReport/QueryDropdownOptions`；選項由 `PromptType`、`AIServiceType` 列舉產生。 |
| 費用查詢 | `POST api/AiCostReport/QueryList`；條件可選，`Page` 預設 1、`Limit` 預設 10。 |
| 費用匯出 | `POST api/AiCostReport/DownloadCostReport`；沿用結束日展開與模型成本重算。 |
| 模型查詢 | `POST api/AiCostReport/QueryAiModelList`；無 request body，空資料回空集合。 |
| 模型新增／更新 | `POST api/AiCostReport/CreateOrUpdateAiModel`；`Service`、`Model` 必填，鍵為 `Service + Model`。 |
| 模型刪除 | `POST api/AiCostReport/DeleteAiModel`；`Service`、`Model` 必填。 |
| 模型價格 | `TokenCount`、`RequestCost`、`ResponseCost` 直接帶入模型資料欄位，異動前須核對單位與來源。 |

## 6. 異常處理與排錯

| 情況 | 先檢查 | 處理方式 |
|---|---|---|
| 下拉或模型清單為空 | API 回應、環境與資料範圍 | 空集合是可回答結果；不要自行新增模型，先確認是否具管理權限及資料是否存在。 |
| 查詢／匯出金額不符 | Start／End date、模型 Service／Model、TokenCount 與價格 | 注意 EndDate 會含完整當日，並保存模型設定快照後再比對原始費用紀錄。 |
| Excel 空白或無法開啟 | 下載回應、檔名、範本與伺服器檔案 | 先確認查詢條件與下載回應，再交由維運檢查 Excel 範本路徑與檔案產出。 |
| `AI 模型操作失敗` | Service、Model、成本欄位與既有清單 | 重新查詢確認是否已寫入；不要重複送出造成錯誤判斷。 |
| `AI 模型刪除失敗` | Service + Model 是否存在、目前帳號權限 | 保留模型鍵值與時間，交由管理員／維運查詢資料庫結果。 |
