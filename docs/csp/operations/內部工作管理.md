# MI 內部管理

## 文件定位與敘述狀態

本頁是內部管理功能的入口摘要；各功能的完整操作、資料邊界與錯誤排查以對應單頁文件為準。

- **現行事實**：本頁整理管理、維運與支援人員常用的內部功能入口。
- **歷史規則**：未標示目前版本的字數、通知或排序細節，可能來自既有手冊與需求紀錄。
- **runtime 未確認**：角色可見範圍、按鈕狀態、跨頁同步與部署差異，以當期 UI／API／授權設定為準。

本篇給管理職、維運與支援人員使用，整理公告、跑馬燈、文件、系統功能、系統角色、帳號、撥號日期、小結清單、外部服務呼叫紀錄、AI Prompt、AI 費用、客戶進階查詢、商品加量、商品話術、即時客服狀態、代理人、行事曆、直播／見面會管理、Domain 設定、工作日、郵件通知紀錄、質檢標準、名單小組與名單轉派、通用審核。

## 公告與跑馬燈

- 詳細跑馬燈操作請見[跑馬燈管理](33-跑馬燈管理.md)。

- 公告可依類型、主題、公告人查詢；首頁每頁 15 筆，管理頁每頁 10 筆。
- 管理職可新增、編輯、刪除、置頂與郵寄公告；標題最多 60 字，內容最多 8,000 字。
- 置頂取消日期預設一個月後；公告未填日期時，起日為當日、迄日為 2099/12/31。
- 跑馬燈內容最多 50 字，每則最多顯示 10 分鐘，新訊息會覆蓋舊訊息；歷史查詢範圍為近 30 天。
- 發送對象受部門與管理權限限制；同組一般權限可查同組人員發送內容。

## 文件管理、系統功能與訊息

- 【客服文件管理】可查詢文件、編輯／新增分類、編輯／新增文件及發送文件；詳細操作請見[客服文件管理](30-客服文件管理.md)。
- 【系統功能】供管理職維護功能群組、子功能、功能網址與區塊設定；詳細操作請見[系統功能](01-系統功能.md)。
- 會員儀表板的文件管理可查 OB 商品總表、信用卡分期現況總表及各通路促銷總表。
- 【即時客服狀態】可用狀態圓餅圖篩選、隱藏單位，並以 Shift＋滑鼠左鍵進行多條件排序。
- 【簡訊審核】支援客代排序與申請人搜尋。

## 商品加量與商品話術

- 【商品加量管理】查詢一般／OB 商品加量清單，依 `skip`／`take` 分批載入，並提供完成、刪除與 Excel 匯出；完成／刪除會通知申請人，詳細的可用量、applicant 與例外邊界請見[商品加量管理](40-商品加量管理.md)。
- 【商品話術管理】維護話術列表、Domain 話術模板、明細、銷售編號綁定與新增／更新／刪除；商品名稱查詢走商品搜尋流程，詳細的驗證與快取邊界請見[商品話術管理](36-商品話術管理.md)。
- 【商品訊息】屬訂單客服管理的多重碼唯讀歷程，不是本頁的維護功能；需要查閱時請從[商品訊息](19-商品訊息.md)進入。

## 系統角色與撥號日期

- 【系統角色】分開維護角色群組、角色基本資料、功能／區塊權限與角色成員；詳細操作請見[系統角色](02-系統角色.md)。
- 【撥號日期管理】維護外撥前置碼判斷使用的日期清單；日期異動採版本檢查，詳細操作請見[撥號日期管理](48-撥號日期管理.md)。
- 【小結清單】供維運／管理查詢指定專員近一小時的電話小結並補登完成時間；不取代通話後的[電話小結作業](13-電話小結作業.md)。

## 帳號與外部服務紀錄

- 【帳號設定】從使用者維度查詢啟用帳號與調整角色；AD 帳號開通、鎖定與解鎖不在 `/User` 頁面，詳細操作請見[帳號設定](03-帳號設定.md)。
- 【外部服務呼叫紀錄】依請求時間與分頁查詢 API request／response，供維運追查串接問題；詳細操作請見[外部服務呼叫紀錄](52-外部服務呼叫紀錄.md)。

## AI 與客戶進階查詢

- 【AI Prompt 管理】維護 Prompt 類型、Template 與模型設定；儲存後清除 Prompt 快取，詳細操作請見[AI Prompt 管理](<53-AI Prompt 管理.md>)。
- 【AI 費用報表】查詢／匯出 AI 費用並維護模型成本設定；報表成本會依模型資料重算，詳細操作請見[AI 費用報表](<54-AI 費用報表.md>)。
- 【客戶進階查詢】以 8 碼客戶編號查詢進階聯絡資料並留下稽核紀錄；Oracle 查詢與 MariaDB log 的例外處理請見[客戶進階查詢](28-客戶進階查詢.md)。

## 小m 文件與使用紀錄

- 【小m文件管理】維護文件、段落、標籤與 FAQ；文件主檔／段落、檔案系統與 Qdrant 向量是不同資料邊界，詳細驗證與失敗處理請見[小m文件管理](55-小m文件管理.md)。
- 【小m使用紀錄】只查詢 `/DocumentQARecord` 的問答紀錄清單與明細；月報以日期區間及分頁結果盤點，不提供重跑、刪除或修正紀錄，詳見[小m使用紀錄](56-小m使用紀錄.md)。

## 排程工作狀態

- 【排程工作狀態】只查詢 `/JobStatus` 的 `schedule_task` 清單；頁面狀態不等於外部 JOB、主機或容器即時健康狀態。
- 需核對排程是否部署或執行時，將 `Name`、`RunServer`、時間、`Status` 與 CSP 排程清單及 JOB log 交叉比對；頁面沒有啟停、重跑或維護 API，詳見[排程工作狀態](50-排程工作狀態.md)。

## 工作日與郵件通知紀錄

- 【工作日管理】位於系統管理選單，入口 route 為 `/WorkingDay`，可查年度與工作日、單筆新增／更新及匯入 CSV；完整 API、日期／欄位規則與未定義邊界請見[工作日管理](51-工作日管理.md)。
- 【郵件通知紀錄】位於系統管理選單，入口 route 為 `/MailNotice`，目前只有選單、route 與 0 issue 已確認；尚無足夠來源確認現行操作，請見[郵件通知紀錄](57-郵件通知紀錄.md)。

## 代理人設定

1. 主要由管理職設定代理人；代理人可在被代理人請假時代為審核簡訊、訂單質檢等案件。
2. 可用姓名或帳號搜尋人員。
3. 每人最多設定 7 位代理人。
4. 代理清單可供管理職確認目前可代理的人員。

詳細流程請見[使用者設定](31-使用者設定.md)。

## 行事曆

- 詳細瀏覽操作請見[行事曆](38-行事曆.md)；`/Meeting` 的管理維護請見[行事曆管理](39-行事曆管理.md)。

- 右上角行事曆 icon 可查看月／週／列表；專員只能看到自己單位的項目。
- 紅點表示隔日有課程、活動、直播等事項；開啟行事曆後消失，下次登入可能再次顯示。
- 活動同日依時間及類別排序：課程、名單、直播、活動、商品、維運、其他。
- 管理職可新增、修改、刪除活動與管理標籤；標籤最多 5 字、最多選 3 個。
- 一般使用者只能查看；行事曆管理可設定部門、起迄時間與網址。

## 直播／見面會報名

- 詳細報名、歷史場次與權限邊界請見[直播／見面會報名](18-直播-見面會報名.md)。
- 專員線上預約直播，管理職查詢直播報名名單；已報名人數可依處查看統計。

## 直播／見面會管理

- 【直播／見面會管理】供具權限人員維護活動主檔、活動內容、報名統計與管理名單匯出；詳細操作請見[直播／見面會管理](37-直播-見面會管理.md)。
- 活動管理與客戶報名分開：活動主檔使用管理入口，客戶報名／取消報名使用[直播／見面會報名](18-直播-見面會報名.md)。

## 名單轉派

- 詳細申請操作請見[名單轉派申請](43-名單轉派申請.md)；查詢與後續狀態請見[名單轉派查詢](45-名單轉派查詢.md)。

- 【名單轉派申請】駁回會通知申請人。
- 【名單轉派審核】完成審核後通知專員有新名單。
- 【名單歷程查詢】可用「客戶經營」條件篩選客代，供管理職查閱；詳細操作請見[名單歷程查詢](42-名單歷程查詢.md)。
- 名單轉派的審核、代理與例外處理請見[名單轉派審核](44-名單轉派審核.md)；組別與成員維護請見[外呼組別管理](41-外呼組別管理.md)。

## 名單小組與 Domain 設定

- 【名單小組管理】目前只有沉澱客戶流程：輸入客代、先檢查最新歷程是否為沉澱名單，查到客戶名稱後才能提交回收；詳細的 Fugo 邊界與例外請見[名單小組管理](46-名單小組管理.md)。
- 【Domain管理】維護通用 Domain Schema／Data、型別限制與啟用狀態；Schema、Data 與 JSON 值的資料邊界請見[Domain管理](49-Domain管理.md)。

## 質檢標準

- 【質檢項目維護】維護訂單質檢共用的質檢標準清單，提供新增、編輯與快取更新；目前來源未證實刪除或啟停功能，操作細節請見[質檢項目維護](27-質檢項目維護.md)。

## 通用審核

- 【審核作業】提供待審／已審清單、審核人選擇、審核狀態更新與審核人調整；詳細操作請見[審核作業](32-審核作業.md)。
