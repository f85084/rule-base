# 質檢查詢

## 敘述狀態與查核界線

- **現行事實**：本頁正文依目前列出的頁面用途、操作流程與來源整理。
- **runtime 未確認**：未在目前環境實際驗證的角色按鈕、API 回應、資料同步、保存期限與版本差異，不視為目前保證；以當期 UI、API 與授權設定為準。

本頁給質檢人員、主管與維運人員查詢、檢視、匯出及追蹤質檢案件使用。網站路由為 `/OrderQAQuery`；實際填寫與判斷請看[訂單質檢](24-訂單質檢.md)。

## 1. 查詢前確認

1. 先確認目前帳號是一般權限或管理權限，以及可查詢的部門與時間範圍。
2. 確認要查的是指派時間、質檢日期、結案時間或其他頁面提供的時間條件。
3. 若要查特定客戶，準備客代；若要查特定案件，準備質檢單或關聯訂單資訊。
4. 涉及附件、上訴或歷程時，確認帳號有對應查看權限。

質檢查詢的時間條件曾多次調整，包含預設指派日期、起迄範圍與一般權限限制；現場若與歷史文件不同，應以目前畫面提示與部署版本為準。

## 2. 查詢質檢案件

1. 進入【質檢查詢】頁面。
2. 先設定必要的時間條件，再依客代、專員、質檢者、質檢類型、案件狀態或其他可用條件縮小範圍。
3. 按【查詢】後確認結果筆數與列表筆數一致。
4. 開啟案件前先核對客代、訂單、質檢日期、指派人員與目前狀態。
5. 若要查看完整內容，使用【編輯】或檢視功能；編輯通常會另開視窗，關閉後回到查詢列表確認結果。

查詢條件變更後應重新送出查詢，不要沿用上一組條件的列表結果。遇到筆數與顯示資料不一致時，保留查詢條件、時間、頁碼與畫面截圖，方便後續追查。

## 3. 查看附件、歷程與上訴

- 附件能否查看取決於目前帳號、案件歸屬與附件權限；看不到附件時先確認權限，不要直接判定附件遺失。
- 查詢頁可用來確認案件是否已結案、作廢、上訴或進入複核；實際處理流程請回到[訂單質檢](24-訂單質檢.md)。
- 上訴功能異常時，記錄案件編號、原處理結果、上訴時間、登入角色與畫面提示。
- 若需要轉派審核人，確認新處理人員、代理人或管理權限，完成後回查案件歷程。

質檢內容中的 Connection ID 可供上訴或音檔查核使用；需要聽取通話時，將 Connection ID 帶到[調聽音檔](22-調聽音檔.md)查詢。

## 4. 匯出報表

匯出前先確認：

1. 查詢條件與時間範圍正確。
2. 結果是否包含客代、質檢者、處理人員、質檢類型、分數、上訴與結案資訊等必要欄位。
3. 是否需要每日、每月或年度報表。
4. 無質檢者 2 或空值欄位是否應保留空白，而不是誤填其他人員。
5. 匯出檔案筆數與畫面結果是否相符。

匯出完成後開啟檔案抽查欄位、編碼、日期與筆數。若資料不完整，保留原始查詢條件與匯出時間，不要只重新下載而未記錄差異。

## 5. 作廢與結案判讀

- 【作廢】會影響案件是否列入後續統計，操作前先確認案件是否已產生處理、上訴或報表紀錄。
- 【結案】代表目前質檢流程完成，不等同於所有相關客訴或訂單問題已完成。
- 報表與查詢結果需依目前狀態、指派時間、質檢日期及結案時間判讀，不要只看建立時間。

## 6. 寫入與副作用

- 本頁的查詢與匯出是讀取／產出檔案操作；匯出不會改變質檢案件狀態。
- 【作廢】會寫入案件狀態，可能影響後續統計；送出前要確認案件編號、目前狀態與是否已有上訴或結案紀錄。
- 若本頁提供編輯、上訴或結案入口，完成後必須重新查詢案件與歷程，分別確認狀態寫入及報表資料是否同步；不要以視窗關閉判定成功。

## 7. 常見異常

| 現象 | 先確認 |
|---|---|
| 查不到案件 | 時間欄位、起迄範圍、客代、部門、權限與案件是否已作廢。 |
| 筆數與列表不一致 | 查詢條件、分頁、排序、資料更新時間與是否重複送出查詢。 |
| 編輯按鈕看不到 | 一般／管理權限、案件狀態與目前處理人員。 |
| 附件無法查看 | 附件權限、案件歸屬與附件是否確實上傳。 |
| 上訴功能異常 | 案件狀態、上訴時間、登入角色與既有歷程。 |
| 匯出資料不完整 | 查詢範圍、報表類型、欄位空值、筆數與匯出檔案編碼。 |
