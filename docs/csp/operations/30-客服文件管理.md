# 客服文件管理

本篇是 CSP／MI `/Document` 文件管理入口，供管理職與具備文件維護權限的人員使用。頁面包含分類樹、文件清單、分類／文件維護、附件預覽與下載；文件內容與實體附件屬受控資料，操作時應遵循資料與權限規範。

## 敘述狀態與查核界線

- **現行事實**：目前前端 route 為 `/Document`，頁面提供分類樹、文件清單、預覽與下載入口。
- **推論**：分類樹選取值是文件清單查詢範圍的主要條件；分類與文件的識別值應分開核對，不能只看名稱。
- **runtime 未確認**：各角色的新增／編輯／附件下載權限、檔案大小與副檔名實際限制，以及附件覆蓋後的同步時間，仍以當期 UI、API 回應與授權設定為準。

## 1. 頁面與權限邊界

- 左側為文件分類樹，右側為目前分類底下的文件清單。
- 一般查詢、文件明細與下載依目前登入權限提供；新增／編輯分類、文件與附件需要維護權限。
- 分類與文件的狀態會顯示為「致能」（啟用中）或「失效」（已停用）。操作前先確認選取的是分類還是文件。
- 儀表板文件管理另可查詢已公告的 OB 商品總表、信用卡分期現況總表與各通路促銷總表；這些查詢用途不要與 `/Document` 的主檔維護混在一起。

## 2. 查詢文件

1. 開啟 `/Document`。
2. 在「文件類型」選擇第一層分類；若該分類有第二層，先選取第二層分類縮小範圍。
3. 點選【查詢】。
4. 依結果欄位判讀：
   - 類型／文件：辨識資料是分類目錄或實際文件。
   - 名稱：顯示分類或文件名稱。
   - 狀態：確認目前為致能或失效。
5. 點選分類後，確認右側清單是否只呈現該分類底下的文件。

## 3. 分類維護

### 編輯分類

1. 在清單找到目標分類，點選【編輯】。
2. 確認所屬分類；不選上層分類代表第一層分類。
3. 修改分類名稱與狀態。
4. 建立人員、建立日期、異動人員、異動日期由系統管理，僅供核對。
5. 儲存後重新查詢分類樹與該分類下的文件。

### 新增分類

1. 點選【新增分類】。
2. 選擇所屬上層分類或保留第一層分類設定。
3. 填寫分類名稱與狀態。
4. 儲存後確認分類階層與文件歸屬沒有改變。

## 4. 文件維護

1. 選取文件後點選【編輯】，或由頁面提供的新增文件入口建立新文件。
2. 確認文件分類與文件名稱。
3. 依文件用途設定可傳真、可郵寄、可 Email 的傳遞選項；非必要選項不要任意勾選。
4. 確認文件狀態為致能或失效。
5. 預覽現有 `TEMPLATEDOC` 內容，確認版本與檔名。
6. 需要替換附件時點選【上傳】；新檔案會覆蓋原有文件內容。
7. 儲存後重新查詢、預覽或下載，確認文件名稱、分類、狀態與附件均已更新。

新增文件時，文件名稱與附件是必要資料；副檔名與檔案大小需符合系統驗證。更新文件時，若有提供新附件也必須通過相同格式與大小檢查。

## 5. 下載與傳送前檢查

- 下載前確認文件 ID、文件名稱與分類，避免把相鄰分類的文件當成目標文件。
- 預覽與下載都應以頁面回傳的文件名稱和內容為準；若查無文件，保留畫面訊息與文件識別資料。
- 若要透過傳真、郵寄或 Email 傳送，先確認文件的傳遞選項與收件資料；郵寄型錄出現地址不存在時，先停止送出並核對客戶地址資料。
- 文件附件屬受控內容，不要將下載檔案、文件內容或收件資料貼入聊天或未受控位置。

## 6. 異常處理

| 情況 | 先檢查 | 處理方式 |
|---|---|---|
| 查不到文件或分類 | 分類層級、狀態、文件 ID 與帳號權限 | 重新查詢並保留條件；若仍無資料，回報「查無資料」與識別資訊 |
| 新增／更新無法儲存 | 名稱、分類、狀態、附件是否存在及格式／大小 | 修正後重送；不要在結果不明時重複建立文件 |
| 預覽或下載失敗 | 文件 ID、附件是否已上傳、權限 | 先回查文件明細；必要時提供文件 ID、檔名與時間給維運 |
| 新附件上傳後內容不符 | 上傳檔案、覆蓋規則、儲存結果 | 重新查詢並下載驗證；保留舊版受控備份，不要自行以檔案覆蓋資料庫內容 |
| 郵寄地址不存在 | 客戶地址與文件傳遞方式 | 暫停郵寄，先修正或確認地址後再送出 |

## 維運查核補充

本節集中分類、文件、附件、下載與傳送的技術查核範圍；一般讀者先依前文畫面操作。檔案保存、權限、部分寫入與外部傳送若未 runtime 驗證，不得自行補成契約。
