# 客訴處理

## 建立客訴

1. 可從訂單或銷退明細的【建立客訴】進入，系統會帶入關聯單號與銷售編號。
2. 填寫客訴主因、關聯類別、解決方式、內容描述與結案反應。
3. 可提供折價券、贈品或得易點數作為解決優惠。
4. 儲存時避免重複點擊；若目前客戶已變更，系統會取消建立。

## 處理狀態

- 已指定：可【反應】或【完成】。
- 已結案：只有管理權限可【重新開啟】。
- 反應／完成都會留下歷程備註；備註可選意見輸入、電郵或簡訊。
- OB 人員只會看到 OB 相關主因；特定主管處理類型一般專員只能反應。
