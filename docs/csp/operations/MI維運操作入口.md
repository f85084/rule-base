# MI 維運操作入口

MI（MONEY IN）是 OB 專員與維運人員處理客戶、通話、訂單及內部工作的主要入口。本目錄以「工作情境」整理，適合第一次接手 MI 的維運人員快速查找。

## 先判斷你要做什麼

| 你現在要處理的事情 | 從這裡開始 |
|---|---|
| 登入、確認環境、查客戶、外撥、補電話小結 | [日常作業](日常作業.md) |
| 商品查詢、加入購物車與接單 | [接單作業](接單作業.md)、[接單與訂單](接單與訂單.md) |
| 客戶資料、簡訊、客訴、聯繫歷史、問卷與待辦 | [客戶服務](客戶服務.md) |
| 活動、限量品登記、直播與活動提醒 | [活動管理](活動管理.md)、[內部工作管理](內部工作管理.md) |
| 公告、跑馬燈、文件、代理人、行事曆、名單轉派 | [公告管理](公告管理.md)、[內部工作管理](內部工作管理.md) |
| 音檔、CTI、播放器或錯誤訊息 | [調聽音檔](調聽音檔.md)、[軟體電話](軟體電話.md)、[CSP 排錯資料](../troubleshooting/README.md) |
| 訂單質檢、缺失判斷、上訴或複核 | [訂單質檢](訂單質檢.md) |
| 質檢案件查詢、報表匯出或案件狀態 | [質檢查詢](質檢查詢.md)、[訂單質檢](訂單質檢.md) |

## 維運處理原則

1. 先確認登入頁或頁腳的版本與主機資訊，再判斷問題是否為環境差異。
2. 先確認目前客戶與帳號，再執行訂單、簡訊、客訴或會員資料異動。
3. 涉及付款、銷退、客訴結案、權限或資料修改時，記錄操作前後的狀態與必要識別資料。
4. 需求單的背景與異常案例，依各操作文件中的「需求單與來源」連結查閱。
5. 完整手冊內容保留在 [MI 完整手冊](MI完整手冊.md)，作為查漏與原文對照，不作為日常第一閱讀入口。
