# 使用者設定

本篇是 CSP／MI 的使用者設定操作入口，對應網站路由 `/Agent`。目前此頁面需求主要集中在「代理人設定」：建立、查詢與維護可代為審核的人員，並供名單轉派、簡訊審核、訂單質檢等功能使用。

## 使用前確認

1. 代理人設定主要由管理職維護；專員通常不需要設定代理人，但實際可用按鈕仍以目前帳號權限顯示為準。
2. 先確認被代理人、代理人與部門組織資料，避免把代理關係設給離職人員、本人或不在可用範圍的帳號。
3. 代理設定會影響需要審核人的功能；建立或修改後，應到實際審核頁確認可選到正確的被代理人。

## 查詢與代理清單

- 使用姓名或帳號關鍵字搜尋使用者；搜尋結果應帶出該使用者目前的代理設定，不要只顯示可被選取的人員清單。
- 開啟【代理清單】可查看指定使用者目前可代理的人員；確認燈箱標題、被代理人與代理人欄位對應正確。
- 每位被代理人最多設定 7 位代理人。若已達上限，先檢查既有清單再決定修改或移除，不要重複新增。
- 離職人員不應納入可用代理清單；若搜尋仍出現，記錄人員帳號、部門與查詢時間交由維運確認人員資料同步。

## 新增與修改代理人

1. 搜尋並選取被代理人，確認姓名、帳號與部門。
2. 選擇代理人，確認代理人仍為在職人員且具備實際審核功能所需的權限。
3. 儲存前核對代理人數量、部門範圍與生效資料；設備號碼欄位若有顯示，需一併確認其值與使用者對應。
4. 修改既有代理關係後，確認修改人與修改時間有正確記錄；若列表資料未更新，重新查詢後再判斷是否儲存失敗。
5. 代理人請假期間，由代理人進入可代理的審核功能，選擇被代理人後處理案件；不應直接共用被代理人的帳號。

## 審核紀錄與名單轉派

- 代理人實際核准或駁回案件時，歷程與匯出資料應標示代理處理，例如審核人姓名後加上「(代)」，以區分原審核人與實際操作者。
- 名單轉派審核需排除原申請人代自己審核的情況；遇到無法核可或找不到案件，先確認目前被代理人、代理人與案件關卡。
- 代理設定完成後，至少驗證一個實際使用功能（簡訊審核、訂單質檢或名單轉派審核），確認被代理人可被選取、案件範圍正確，且歷程記錄的是代理操作。

## 權限與資料邊界

- 使用者設定的代理關係不等於系統角色授權；若代理人看不到功能或案件，需分別檢查頁面權限、部門範圍、被代理人設定與案件狀態。
- 部門組織資料由後端查詢帶出；切換部門或關鍵字後若代理清單未同步，先重新查詢並確認目前選取的使用者。
- 代理清單異動應保留修改人與修改時間，供維運追查錯誤設定或審核爭議。

## 常見異常

| 現象 | 先檢查 | 處理方式 |
|---|---|---|
| 搜尋使用者後沒有代理清單 | 關鍵字、目前選取使用者、部門資料 | 清除後重新搜尋姓名／帳號，確認開啟的是該使用者的代理清單 |
| 離職人員仍可被選為代理人 | 人員在職狀態、同步時間 | 暫停新增，記錄帳號與畫面，請維運確認人員資料來源 |
| 無法再新增代理人 | 目前數量是否已達 7 人、是否重複 | 先檢查既有代理清單，移除不再使用的代理關係後再新增 |
| 審核頁找不到被代理人 | 代理設定、登入帳號、審核功能權限 | 重新登入或重新查詢代理設定，再到實際審核頁確認可代理名單 |
| 審核紀錄未標示「(代)」 | 實際操作者、案件歷程與匯出版本 | 保存案件 ID、被代理人、代理人與操作時間，交叉比對歷程與匯出資料 |
| 修改後列表仍顯示舊資料 | 修改人／時間、前端快取、部門查詢結果 | 重新查詢並確認儲存結果；若仍不一致，保留前後畫面供追查 |
