# MI 客戶服務

## 文件定位與敘述狀態

本頁是客戶服務工作情境摘要，詳細頁面操作請回到[客戶查詢](05-客戶查詢.md)、[會員明細](10-會員明細.md)、[聯繫歷史](12-聯繫歷史.md)、[客訴處理](09-客訴處理.md)與[問卷管理](15-問卷管理.md)。

- **現行事實**：本頁整理客戶資料、訊息、客訴、問卷與待辦的跨頁銜接。
- **推論**：處理任何寫入前先核對目前客代，可避免把資料記到錯誤客戶。
- **runtime 未確認**：本摘要沒有取代各頁的角色權限、欄位驗證與同步確認。

本篇整理維運人員處理客戶資料、簡訊、問卷、待辦、客訴與聯繫歷史的工作方式。

## 1. 先確認客戶資料

在會員儀表板確認客代、姓名、會員／OB 會員等級、LINE 綁定、地址、訂單與客戶特性。會員明細中可查看聯絡地址、發票地址、配送地址、手機、E-mail、個人化資料及家人資訊。

- 基本會員資料只有管理職可修改；專員新增的客戶備註不能自行編輯或刪除。
- 新增會員只開放管理職，避免重複客代。
- 電話格式：住家區碼 2～4 碼、電話 5～8 碼、手機 10 碼。
- 配送地址最多 60 字；路、段、街前數字用國字，巷、弄、號、樓用數字。
- 家人資訊由管理職新增／修改／刪除；新增家人後，關聯客代的家人資訊會同步建立。

## 2. 傳送簡訊

1. 從會員儀表板選擇【傳簡訊】。
2. 制式簡訊選擇類型後直接確認。
3. 需要自訂內容時選【其他】，輸入內容後送出；自訂簡訊需組長／管理職審核。
4. 客戶有多支手機時，送出前選擇正確手機。

使用【聯繫歷史】可用關鍵字查詢已發送簡訊，也能重新發送簡訊或電子郵件。

## 3. 查詢聯繫歷史

- 有客代：可查該客戶全部聯繫歷史，接洽人員條件會失效。
- 無客代但指定人員：可查該人員資料。
- 無客代且無指定人員：至少輸入起日或迄日；查詢會限制為單日。
- 日期迄日不可早於起日；關鍵字不可輸入空白鍵。
- 聯繫方式可選客服／語音連線、客服外撥、電子郵件、簡訊、郵寄、傳真、APP 推播與 OB LINE 等。
- Connection ID 可提供管理職調聽音檔；管理權限可在客服進線／外撥後加入播放清單。

## 4. 處理客訴

1. 從訂單或銷退明細按【建立客訴】，系統會帶入關聯單號、銷售編號與關聯類別。
2. 填寫客訴主因、解決方式、內容描述與結案反應。
3. 需要補償時，可選折價券、贈品或輸入得易點數。
4. 【反應】會寫入處理歷程；【完成】會結案；已結案案件只有管理權限可重新開啟。
5. 新增時不要重複點擊儲存；若客戶已變更，系統會取消建立並提示「客戶已變更」。

OB 人員只會看到 OB 相關客訴主因；若為「客服-OB 小組主管處理」，一般專員只能反應，管理職才能完成。客訴右上通知會顯示指定來電或客訴未結，但同類通知通常只顯示一筆。

## 5. 問卷、待辦與通知

- 【問卷管理】可查看客戶未完成問卷。需求與歷史描述曾將 `QuestionOption.Remark=Y` 與備註必填連在一起；目前是否依該設定阻擋送出仍是 **runtime 未確認**，請依[問卷管理](15-問卷管理.md)以當期畫面與實際送出結果核對，不得視為現行保證。
- 【客服員待辦事項】處理指定回電、到貨未聯、超取未聯等工作。
- 名單轉派駁回、新名單、簡訊審核等事件會出現在右上角小鈴鐺。
