# 訊息查詢與通知中心

## 文件定位與敘述狀態

本頁是導航摘要，不取代[訊息查詢](20-訊息查詢.md)與[通知中心](21-通知中心.md)兩份單頁手冊；實際 route、角色權限、資料來源與寫入副作用以兩頁及當期 UI 為準。

- **現行事實**：本頁提供訊息查詢與通知中心的交叉入口。
- **推論**：通知只代表有事件或待辦提示，完整案件狀態必須回原功能查詢。
- **runtime 未確認**：通知合併、已讀同步與各帳號可見範圍未在本摘要頁單獨驗證。

## 訊息查詢

- 詳細的歷史訊息查詢、頁籤、預約發送與附圖規則請看[訊息查詢](20-訊息查詢.md)。
- 可依日期、客戶、聯繫方式與關鍵字查找歷史訊息。
- 簡訊可重新發送；自訂簡訊需依審核流程處理。
- LINE 綁定與 AI 助手請見 [LINE 綁定與 AI 助手](LINE綁定與AI助手.md)。

## 通知中心

詳細的通知來源、處理原則與異常排查請看[通知中心](21-通知中心.md)。

右上角小鈴鐺會顯示電話小結、指定回電、客訴未結、新名單、簡訊審核與名單轉派等通知。點選後通常只會清除顯示，不一定會自動跳轉頁面，因此仍要回到對應功能確認待辦。

需求單：[訊息查詢需求](../requirements/pages/20-訊息查詢.md)、[通知中心需求](../requirements/pages/21-通知中心.md)。
