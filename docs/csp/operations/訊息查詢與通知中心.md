# 訊息查詢與通知中心

## 一般人員操作入口

**這頁做什麼**：提供兩個入口：查過去訊息，以及從小鈴鐺找到待辦後回原功能處理。適用客服與管理職；通知本身不是案件結案工具。

**入口與開始前**：從功能選單開【訊息查詢】，或從右上角小鈴鐺開【通知中心】。先準備客代、日期、關鍵字與要處理的通知來源；看不到某頁先按帳號權限判讀。

**照著做**：

1. 查訊息時選【全部】／【已發送】／【已收件】等頁籤，輸入日期或條件後按【查詢】。預期結果：列表顯示符合條件的訊息。
2. 看通知時先讀時間、來源與客代，再點回原功能頁。預期結果：知道下一個實際工作，不只清除紅點。
3. 若要重送簡訊或處理審核，先開原訊息／案件並核對對象、內容與權限。預期結果：送出前可辨識副作用。

**完成確認與常見問題**：訊息查詢以列表／明細符合日期與內容為完成；通知則要回原案件確認狀態。點通知不跳轉時直接開對應功能；查不到時先縮小日期與客戶條件。

**影響與技術附錄**：重送、審核與通知已讀可能寫入資料或產生外部效果；通知合併、API 與資料來源留在單頁手冊末端。

## 文件定位與敘述狀態

本頁是導航摘要，不取代[訊息查詢](20-訊息查詢.md)與[通知中心](21-通知中心.md)兩份單頁手冊；實際 route、角色權限、資料來源與寫入副作用以兩頁及當期 UI 為準。

- **現行事實**：本頁提供訊息查詢與通知中心的交叉入口。
- **推論**：通知只代表有事件或待辦提示，完整案件狀態必須回原功能查詢。
- **runtime 未確認**：通知合併、已讀同步與各帳號可見範圍未在本摘要頁單獨驗證。

## 通知中心

詳細的通知來源、處理原則與異常排查請看[通知中心](21-通知中心.md)。

右上角小鈴鐺會顯示電話小結、指定回電、客訴未結、新名單、簡訊審核與名單轉派等通知。點選後通常只會清除顯示，不一定會自動跳轉頁面，因此仍要回到對應功能確認待辦。
