# 商品與特殊接單

## 一般人員操作入口

**這頁做什麼**：補充【接單作業】中商品、付款、限量與特殊商品的判讀。它不是獨立下單頁；真正加入購物車與送出仍回 [接單作業](06-接單作業.md)。

**入口與開始前**：先在接單頁確認客代、商品、數量與規格，並確認目前帳號可用的付款／配送選項。特殊商品需要管理／商品單位核示時，不用一般客服帳號猜測解法。

**照著做**：

1. 開商品明細，看 KIT／銷售組合、規格、優惠與配送提示。預期結果：所有必要選項已完成。
2. 加入購物車前確認折價券／活動擇一、限量商品付款與期限。預期結果：購物車內容可被客戶確認。
3. 旅遊、指定客戶或特殊配送商品先查看本頁限制，再回接單頁設定。預期結果：不把不可用付款或銷退方式送出。
4. 送出前核對商品、客戶、金額與配送，按頁面確認後回訂單管理查結果。預期結果：有訂單編號或可讀的錯誤提示。

**完成確認與常見問題**：商品條件與訂單結果可回查。付款方式不見先核對商品／通路；購物車被清空或庫存變化時先確認是否已送出，不要重複成立訂單。

**影響與技術附錄**：付款、庫存、配送與訂單成立都有副作用；上限、期限、資料表與外部服務說明留在後段，不取代畫面確認。

## 用途、入口與敘述狀態

本頁補充[接單作業](06-接單作業.md)的商品、付款與特殊商品邊界，不是獨立下單 route。商品搜尋、購物車與訂單送出均以接單作業目前畫面為準；不同通路、商品或版本可能有不同可用付款方式（**runtime 未確認**）。

- 客服依目前客戶、商品與帳號權限執行接單；需要變價、特殊配送或管理核示時，依頁面授權與核准流程處理。
- 購物車與訂單送出會造成資料與付款／庫存副作用；本頁的限制是送出前的檢查清單，不代表訂單已成立。

## 商品與付款

- KIT 商品需查看「銷售組合」，所有顏色／尺寸都選好後才能加入購物車。
- 購物車最多 30 件；折價券與行銷活動只能擇一。
- 東森幣通常單筆最多折 3,000 元；E 幣 1 枚折 1 元，不能與東森幣合用。
- 付款方式依客戶與商品條件顯示；信用卡需確認授權，ATM 需注意入款期限。

## 限量商品

- 不可使用 POST 或已置入方式搶量。
- 信用卡須訂單成立當日授權；ATM 須當日入款。
- COD 不可回壓指定配達日；限量商品會每日稽核。
- 購物車長時間未送出可能被清除並釋放量。

## 特殊商品

- 旅遊商品不可 COD、提貨券、折價券或紅利金；已訂房／已填使用日期時不可直接銷退。
- 指定客戶商品只能由名單內客戶下單。
- KIT 子商品不同倉庫時，請商品／行銷處重新設定倉庫。

## 正常檢查與異常排查

1. 先核對客代、商品銷售編號、商品類型與可用通路。
2. 再依顏色／尺寸、折扣、付款、配送與特殊商品限制逐項確認。
3. 送出後回查訂單編號、付款授權／入款、配送與庫存結果；不要只看購物車狀態。

| 現象 | 先確認 | 處理方式 |
|---|---|---|
| KIT 無法加入購物車 | 銷售組合、顏色／尺寸是否完整 | 補齊所有子商品選項；不要用其他商品替代。 |
| 付款方式不顯示或授權失敗 | 商品限制、混合付款、信用卡／ATM 時限 | 依當期頁面與付款回應處理；不要向客戶保證已保留庫存。 |
| 限量商品送出後被取消 | 訂單成立時間、授權／入款時間與庫存稽核 | 保留訂單與付款識別，交商品／財務流程核對。 |
| 特殊商品不能銷退 | 是否已訂房／填使用日、商品類型與銷退狀態 | 轉看[銷退管理](08-銷退管理.md)及商品專屬流程，不要直接改一般銷退。 |

需求單：[接單作業需求](../requirements/pages/06-接單作業.md)。
