# 訂單管理

本頁給維運人員查詢與處理既有訂單使用。新訂單建立請看 [接單與訂單](接單與訂單.md)；銷退流程請看 [銷退管理](08-銷退管理.md)。

## 1. 查詢訂單

1. 先查詢並確認目前會員資料與客代。
2. 進入【訂單管理】，依需要查詢全部訂單或只查 OB 通路訂單。
3. 從清單開啟訂單明細；建立時間代表送出訂單時間，不是加入購物車時間。
4. 需要確認客戶當時看到的內容時，查看網路訂單快照，核對商品規格與售價。

### 查詢後的確認順序

1. 先確認訂單編號、客代、客戶姓名與建立時間。
2. 再確認訂單狀態、訂單通路、建立人員與商品項次。
3. 最後查看付款、配送、發票與聯繫紀錄，避免只依客戶口述判斷。

訂單建立時間代表送出訂單的時間，不是商品加入購物車的時間；限量商品或付款期限爭議，應以此時間與系統狀態為準。

## 2. 查看訂單資訊

- 【編輯項目】：查看訂單明細、商品規格、顏色與尺寸。
- 配送單號：點擊連結查看貨運端配送進度。
- 付款資訊：查看付款方式、信用卡授權與付款狀態。
- 退款資訊：查看退款銀行帳戶紀錄，核對帳號與戶名。
- 發票資訊：查看發票類型、載具與發票號碼；捐贈發票不顯示完整號碼。
- 會員明細：手機載具異動會同步影響發票資訊，反向修改也會同步更新。

### 訂單項次

訂單有多個項次時，先確認客戶詢問的是哪一個項次。建立客訴時可選單一項次，也可選【全部項次】；選擇全部項次後，系統會依項次建立多筆客訴，客訴主因、緊急指數、解決方式與描述相同，但銷售編號依項次分別帶入。

### 網路訂單快照

網路訂單快照用來還原客戶下單當時的商品規格與售價，適合處理「客戶看到的價格／規格與目前頁面不同」的問題。查詢時要同時比對快照、目前訂單明細與後續異動紀錄。

## 3. 修改訂單

- 訂單成立後可依權限修改商品顏色／尺寸、付款資訊及符合條件的發票資料。
- 可使用【補折價券】、變價或補行銷活動，但通常需符合：訂單狀態為「訂單受理」、建立人員為專人／IVR，且訂單金額等於商品單價。
- 變更價格需輸入變更原因並由主管輸入帳號密碼授權。
- 信用卡可在付款資訊中申請延長分期；無法直接選擇時，先查商品設定與 MI 文件管理的信用卡分期總表。

### 補折價券或行銷活動

訂單成立後要補折價券、變價或補 VP，先確認：

- 訂單狀態為「訂單受理」。
- 建立人員為「專人」或「IVR 訂單」。
- 訂單金額等於商品單價，未參與其他行銷活動、折價券或變價。

若不符合條件，不要以人工方式承諾補發，應轉交商品／行銷單位確認。

### 信用卡授權與分期

1. 從【付款資訊】展開信用卡資料，確認目前授權狀態。
2. 申請延長分期時，先確認商品分期設定與客戶可用卡別。
3. 高單價商品若符合公司條件，依核准流程申請；未達門檻時需逐級上呈。
4. 限量商品的信用卡授權通常必須在訂單成立當日完成，隔日仍為「訂單受理」可能被取消。

## 4. 付款、配送與發票欄位

### 付款資訊

付款方式依商品與客戶條件顯示，常見方式包括信用卡、COD、ATM、LinePay、暫存付款、POST、現金帳戶、禮券、提貨券、東森幣、得意點與台灣 Pay。查詢時要確認是否混合付款，以及每種方式的實付金額。

- 信用卡：查看卡片、分期與授權結果。
- ATM：查看轉帳帳號、付款截止日與入款狀態；未入款訂單可能自動取消。
- COD：訂單可貨到付款，但不能回壓指定配達日。
- 東森幣／E 幣：查看折抵金額與折抵後餘額；兩者不可合併使用。

### 配送資訊

宅配可查看收件人、聯絡電話、地址、要求配達日／時段、快速到貨與備註；超取可查看門市、溫層與取貨資訊。要求配達日需排除週日，特殊日期或長時間延後需依權限核示。

若客戶要求修改配送地址、電話或取件資料，先確認訂單目前狀態是否允許修改，再確認變更後是否會影響出貨或銷退流程。

### 發票資訊

可查看捐贈發票、二聯式電子／紙本及三聯式紙本發票。三聯式發票需確認統一編號與抬頭；旅遊商品則可能使用代收轉付收據而非一般發票。

## 5. 訂單客訴

從訂單明細按【建立客訴】：

1. 系統帶入關聯單號與銷售編號。
2. 若只針對單一項次，選該項次；選【全部項次】時會依所有項次建立客訴。
3. 客訴主因、緊急指數、解決方式與內容描述可依流程填寫。
4. 建立完成後回到訂單明細。

OB 通路訂單若由非該客戶 OB 維運專員處理取消／退貨，系統會提示通知維運人員。客戶同意時建立「服務類－客服－OB 小組處理」客訴；客戶堅持線上處理時，依權限辦理並同步建立客訴供 OB 關懷。

## 6. 拒收與取消提示

- 商品已出貨但客戶尚未收到且不要貨：依拒收流程處理，不要直接當成一般銷退。
- 出貨中的廠送到廠取貨商品按【訂單取消】時，先確認是否需要挽留；可請客戶若來不及攔截則直接拒收。
- 出貨完成的庫送／廠送到廠取貨商品按【訂單銷退】時，先確認客戶是否已收到。
- 未收到時選【請客拒收】；超商取貨則請客戶不要取貨。

## 7. 常見狀態判讀

| 狀況 | 維運處理 |
|---|---|
| 銷退中 | 轉看 [銷退管理](08-銷退管理.md)，紅色通常代表銷退中。 |
| 銷退完成 | 黑色通常代表銷退完成，確認銷退入庫與退款資訊。 |
| 信用卡未授權 | 先確認付款方式與授權狀態，再依商品期限處理。 |
| ATM 未入款 | 確認訂單成立日、付款截止日與是否有核准展延。 |
| 配送進度不明 | 點擊配送單號連到貨運端查詢。 |
| 訂單內容與客戶描述不同 | 先查網路訂單快照，再確認修改紀錄與商品活動。 |

## 8. 維運交接紀錄

遇到需要轉交商品、行銷、物流、財務或 OB 維運人員的案件，至少記錄：

- 客代與訂單編號。
- 商品銷售編號與項次。
- 目前訂單／付款／配送／銷退狀態。
- 已執行的操作與畫面提示。
- 客戶要求、承諾內容與下一步負責單位。

不要只記錄「已處理」或「請協助」，避免後續人員無法重現判斷依據。
