# LINE 綁定與 AI 助手

## 手機綁定

1. 從東森購樂趣 LINE@ 的「點我綁定」進入會員綁定手機驗證。
2. 輸入客戶手機與姓名，按【取得手機驗證碼】。
3. 客戶輸入收到的簡訊驗證碼後完成綁定。
4. 若綁定失敗，請客戶截圖並傳到東森購樂趣對話框，由管理員確認 LINE@ 後台資料。

## AI 助手

- 【AI 智慧摘要】：分析近期最多 300 則對話；至少需有 20 則對話才適合產生摘要。
- 【顧客需求】：從對話分析需求，點選後可跳到對應訊息。
- 【常回覆時段】：分析客戶通常回覆的時間，協助安排聯繫。

需求單：[訊息查詢需求](../requirements/pages/20-訊息查詢.md)。
