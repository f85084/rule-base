# 帳戶明細

## 1. 用途、入口與權限視角

帳戶明細用來依目前客戶查詢各類點數、折價券與帳戶交易。現行前端 route 為 `/DiscountTransaction`。頁面會依登入者可用的客戶功能權限載入分頁；某些管理或取消按鈕若不顯示，不代表資料不存在。

## 2. 分頁與欄位

目前頁面分頁如下，分頁採延遲載入，各分頁是獨立查詢：

1. 東森幣
2. 東森幣到期查詢
3. 折價券
4. 現金帳戶
5. 禮券
6. W幣（提貨券）
7. 得易點
8. 樂透金
9. 樂透金到期查詢
10. 藍鑽點數
11. 東森現金券
12. 東森現金券到期查詢

東森幣到期欄位至少要核對贈品名稱、效期迄、餘額、總額與使用額度。E 幣／東森幣交易明細則依當期分頁欄位判讀交易日期、交易狀態、備註與金額；需求頁記錄 E 幣查詢期間曾調整為 90 天，實際日期限制仍以當期 UI 驗證為準（**runtime 未確認**）。

## 3. 正常操作流程

1. 先確認目前客代與帳戶類型，再開啟 `/DiscountTransaction`。
2. 選擇目標分頁，輸入該分頁要求的日期、交易或券號條件。
3. 點選查詢，先確認結果客代／帳戶識別、交易或券號，再判讀餘額、效期、狀態與備註。
4. 切換分頁時重新確認查詢條件；不要把一個分頁的日期或空結果套用到另一分頁。
5. 需要取消或異動時，只使用當期 UI 顯示且帳號有權限的按鈕，完成後重新查詢核對結果。

## 4. 資料來源與合併方式

- 每一分頁呼叫不同的帳戶／交易查詢入口；前端不把 12 個分頁合成一張共用交易表。
- 東森幣、到期資料、現金、禮券、提貨券、得易點、樂透金、藍鑽及現金券各自保留來源識別與欄位意義；同名金額不得直接相加。
- 分頁查詢通常以目前客代為上下文；客代切換後必須重新查詢，避免把上一客戶的結果留在畫面上。
- 單一分頁查不到資料只表示該帳戶／條件沒有結果或該分頁請求失敗；其他分頁仍可能正常。

## 5. 寫入與副作用

本頁主體是唯讀查詢，但目前 API 來源包含交易取消入口；若畫面出現【取消】或其他異動按鈕，送出前要確認客代、交易識別與權限。取消或異動可能改變交易狀態，完成後應重新查詢並保留回應，不要以分頁切換或關閉視窗判定成功。

## 6. 空資料、部分失敗與錯誤排查

| 現象 | 先檢查 | 判讀與處理 |
|---|---|---|
| 整頁無法開啟 | 登入、目前客代與共用服務 | 先視為頁面／共用服務問題。 |
| 單一分頁空白或查無資料 | 分頁、客代、日期／券號條件及該分頁載入錯誤 | 以同一客代重查；不要推論其他帳戶也沒有資料。 |
| 日期不能送出 | 分頁日期規則、起訖順序與當期限制 | 依 UI 驗證修正；E 幣 90 天規則需以當期畫面確認。 |
| 到期資料與交易資料不一致 | 帳戶類型、交易狀態、效期與資料時間 | 分別保存分頁結果，交維運核對來源，不要自行合併。 |
| 取消／異動後結果未變 | API 回應、交易識別、重新查詢時間 | 先確認是否部分成功，再回查；不可重複送出。 |
| 欄位缺少或只顯示代碼 | 分頁版本、欄位設定、來源回應 | 保留客代、分頁、交易識別與時間供維運查核。 |
