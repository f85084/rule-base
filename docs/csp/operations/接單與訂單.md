# MI 接單與訂單

## 文件定位與敘述狀態

本頁以「客戶要買東西」的跨頁情境整理接單、付款、配送、發票、訂單與銷退；細節以[接單作業](06-接單作業.md)、[訂單管理](07-訂單管理.md)及[銷退管理](08-銷退管理.md)為準。

- **現行事實**：本頁列出接單至訂單後續處理的主要檢查順序。
- **歷史規則**：付款上限、配送天數與核示門檻若來自手冊／需求紀錄，需依單頁來源與當期版本確認。
- **runtime 未確認**：商品、通路、付款與帳號權限的實際可用組合，以當期 UI／API 回應為準。

本篇用「客戶要買東西」的流程整理商品、購物車、付款、配送、發票、訂單管理與銷退。

## 1. 查商品與加入購物車

1. 在【接單作業】查詢商品；KIT 商品會有 `K` 標記，需從「銷售組合」查看完整內容。
2. 需要選顏色／尺寸的 KIT 商品，所有選項都完成後才能加入購物車。
3. 購物車最多 30 件；系統會自動判斷折價券與行銷活動。
4. 折價券與行銷活動不可同時使用，以最後選擇的方式為準；變更價格需填原因並由主管授權。

## 2. 設定付款

可用付款方式包括信用卡、COD、ATM、LinePay、暫存付款、POST、現金帳戶、禮券、提貨券、東森幣、得意點與台灣 Pay；可依商品與客戶條件混合付款。

- 東森幣單筆通常最多折 3,000 元；E 幣 1 枚折 1 元，E 幣不能與東森幣合併。
- COD 上限 50,000 元；台灣 Pay 不可與信用卡混合，不同公司別商品也可能不顯示。
- 信用卡會先檢查是否已被其他客戶使用；畫面顯示使用人數只供內部參考，不可向客戶透露人數。
- 付款方式變更後要按【確認】；直接關閉視窗會提示尚未儲存。
- 限量商品的信用卡須於訂單成立當日授權，ATM 須於當日入款，否則隔日可能被取消。

## 3. 設定配送

### 宅配

- 可設定收件人、手機／市話、要求配達日／時段、快速到貨、地址與備註。
- 要求配達日最多為接單日後 365 天；非預購商品通常需 7 天後，週日不可選。
- D+11～20 需處長核示、D+21～30 需部長核示、D+30 以上需事業部主管核示。
- 配送時段為 09～12 或 13～18；18 點後不要承諾可配送。
- 備註最多 30 字，只記錄特殊配送需求，不要只把預計日期寫在備註欄。
- 地址新增需組長帳號密碼；管理權限可直接新增。

### 超取

- 只有符合條件的商品才顯示超取分頁；可選全家、萊爾富、7-11 常溫、7-11 冷凍及全家冷凍。
- 常溫超取只能 COD 或 COD＋東森幣。
- 冷凍超取不可 COD，可用信用卡、ATM、LinePay、禮券、提貨券、東森幣或混合付款。
- 冷凍超取需提醒客戶：除商品瑕疵或品項錯誤外，通常無法退換貨，逾期未領可能收取 300 元處理費。

## 4. 設定發票與送出

可選捐贈、二聯式電子、二聯式紙本及三聯式紙本發票。完成付款、配送與發票設定後：

1. 檢查下方總覽與實付金額。
2. 按【確認訂單】，確認提示話術與訂單內容。
3. 按【確定】成立訂單；若放棄結帳，購物車會清空。
4. 有信用卡付款時，依畫面決定立即授權或稍後從訂單管理授權。

## 5. 特殊商品

- 旅遊商品為預購型票券，不可 COD、提貨券、折價券或紅利金；國旅卡只適用國內行程，需使用本人正卡。
- 旅遊商品未預約時可直接銷退；已訂房或已有使用日期時，需建立 C/S「待建銷退」由二線處理。
- 指定客戶商品只能由名單內客戶下單。
- KIT 商品若子銷編位於不同倉庫，需請商品／行銷處重新設定倉庫。

## 6. 訂單管理與銷退

- 訂單管理可查看網路訂單快照、配送進度、付款／授權、退款、發票、折價券與變價。
- 訂單明細可【建立客訴】；系統會帶入訂單與銷售編號。
- 銷退狀態依序可能為銷退受理、銷退取消、收回指示、銷退進行中、等待驗收入庫、銷退確認或銷退中止。
- 只有銷退受理或收回指示可取消退貨／換貨或修改取件資料。
- 換貨訂單在等待出貨、出貨指示或出貨進行中，可使用【換貨改銷退】。
- 銷退中止通常會自動產生客訴；銷退取件資訊可透過配送單號查貨運進度。
- 銷退清單中紅色代表銷退中，黑色代表銷退完成。
