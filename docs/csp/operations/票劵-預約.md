# 票劵／預約

本頁給客服與維運人員查詢自然美／健康相關票券、確認使用狀態及進入預約入口使用。網站路由為 `/NaturalBeauty`；預約外撥則由電話小結與 TM 名單流程承接。

## 1. 查詢客戶票券

1. 先確認客代、客戶姓名與目前處理目的。
2. 進入【票劵／預約】，預設查看未使用票券。
3. 需要查歷史資料時，切換【已使用】或【全部】。
4. 票券通常依效期由新到舊排序；過期票券會以灰色顯示。
5. 開啟票券明細，核對券號、效期、有效狀態、票券內容與關聯訂單。

效期為空白時，來源手冊記載為無效期限制；仍應以目前票券狀態與活動規則為準。無法使用的票券也可能以灰色顯示，不要只依文字顏色判定已使用或已失效。

## 2. 關聯訂單與票券內容

- 票券明細的關聯單號可連到【訂單管理】，用來確認來源訂單、付款與銷退狀態。
- 票券內容會列出該票券名稱包含的項目，向客戶說明時要以明細為準。
- 自然美訂單銷退時，相關票券券號與狀態可能會反灰；先確認銷退結果，再判斷票券是否仍可使用。
- 票券顯示重複時，先核對客代、券號、關聯單號與票券狀態，不要直接重複建立預約。

## 3. 自然美預約

需要進行自然美預約時，從票券明細或目前提供的預約入口進入 Regal 預約平台：

1. 先確認票券有效、客戶資料與可預約項目。
2. 將客戶要預約的日期、項目與票券內容核對清楚。
3. 依畫面完成預約，完成後回查票券與預約結果。
4. 若出現「Regal 預約平台出現未知錯誤，請聯繫 Regal 資訊窗口」，記錄客代、券號、操作時間與畫面訊息，再轉交窗口處理。

若票券已使用、失效、過期或與銷退訂單有關，先確認目前狀態再回覆客戶，不要直接承諾可預約。

## 4. 健康抵用券預約入口

需求資料包含健康抵用券預約登記入口與 API 串接調整。操作時：

- 先確認客戶是否持有符合條件的健康抵用券。
- 確認預約項目、日期與使用條件。
- 送出後回查登記結果與通知，必要時保留 API／畫面錯誤資訊。
- 若入口或功能列文案與目前畫面不同，記錄版本與環境，避免以舊文案指引客戶。

## 5. 預約外撥

預約外撥不是本頁票券明細功能，而是從【電話小結】設定【重新安排】後，由 TM 名單顯示：

1. 外撥結束後在電話小結設定下次聯繫時間。
2. 預約日期當天從 TM 的【預約外撥日期】查詢名單。
3. 系統通常會在預約時間前 30 分鐘透過小鈴鐺提醒。
4. 預約外撥需在目前允許的時間範圍內安排；來源手冊記載重新安排最多三個月內。
5. 若名單已回收或維運專員已變更，預約外撥資料可能同步清除，需回查客戶待辦與名單狀態。

詳細流程請看[電話小結作業](電話小結作業.md)、[TM 名單推薦](TM名單推薦.md)與[通知中心](通知中心.md)。

## 6. 常見異常

| 現象 | 先確認 |
|---|---|
| 查不到票券 | 客代、票券狀態篩選、效期、券號與是否已銷退。 |
| 票券變灰 | 是過期、已使用、無法使用或銷退反灰，需查看狀態欄位與關聯訂單。 |
| 預約平台錯誤 | 客代、券號、票券有效性、操作時間與 Regal 錯誤訊息。 |
| 預約外撥沒有出現 | 重新安排時間、名單回收、目前維運專員與小鈴鐺通知。 |
| 關聯訂單不正確 | 券號、客代與關聯單號是否對應同一筆訂單。 |
