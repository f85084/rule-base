# 接單作業

本頁給客服與維運人員從商品查詢開始建立訂單使用。網站路由為 `/Order`；購物車、付款、配送與發票的完整流程請看[接單與訂單](接單與訂單.md)。

## 1. 接單前確認

1. 先確認目前登入帳號、作業時間與可用權限。
2. 依客戶需求查詢或選定會員；若要把商品加入購物車並結帳，需先確認購買對象正確。
3. 若從 TM 名單進入，確認客代、會員資料與目前聯繫對象一致。
4. 先問清楚商品、數量、規格、配送方式與付款需求，再開始建立購物車。

一般專員在 22:00 至 08:00 點選結帳時，系統可能禁止進入結帳流程；遇到時間限制應依系統提示處理，不要重複點擊繞過限制。

## 2. 查詢商品

1. 進入【接單作業】，輸入銷售編號、商品關鍵字或可用的查詢條件。
2. 查詢前後確認關鍵字沒有前後空白；銷售編號與售價欄位依畫面規則輸入數字。
3. 開啟商品明細，確認商品名稱、售價、商品介紹、商品話術、包裝方式、贈品、配送方式與提示訊息。
4. 商品明細頁的銷售編號可連到相關商品資料；需要向客戶說明時，以目前商品頁與活動條件為準。

商品搜尋本身可能不要求先選客代，但加入購物車與後續結帳時仍要確認客戶資料；未選客戶時若畫面導向會員查詢，先完成客戶選擇再繼續。

## 3. 加入購物車

1. 確認商品適用目前接單通路，點選【加入購物車】。
2. KIT 或有規格的商品，完成所有顏色、尺寸與款式選擇後才算加入成功。
3. 確認數量、可接單量、庫存提示與近期訂單提示。
4. 購物車最多 30 件；若同品需要增加數量，使用數量／加購功能並回看商品項次。
5. 加入後檢查購物車項次與客戶是否正確，再決定繼續購物或進入結帳。

若商品不可前台接單、缺少必要規格或沒有可接單量，依畫面錯誤提示處理，不要以其他銷售編號替代下單。

## 4. 特殊商品與通路

### KIT 商品

- 先查看銷售組合與所有子商品。
- 所有顏色／尺寸選項完成後才能加入購物車。
- 若子銷編位於不同倉庫，需請商品／行銷單位重新設定倉庫。
- 建立客訴時通常要選擇對應的細項商品，不能只記錄 KIT 主銷編。

### 指定客戶商品

指定客戶商品只能由符合名單的客戶下單。若客戶不在指定範圍，先確認商品條件與客戶資料，不要承諾可由人工放行。

### 旅遊與特殊商品

旅遊商品可能限制付款方式、折價券與銷退條件；已訂房或已有使用日期時，不要直接當成一般商品銷退，應轉由對應單位處理。

## 5. 結帳前交接

進入結帳前，至少確認：

- 客代與會員姓名。
- 商品銷售編號、商品名稱、數量與規格。
- 商品通路、配送方式與特殊提示。
- 優惠、折價券／行銷活動是否符合條件。
- 客戶指定的付款與配送需求。

接著依[接單與訂單](接單與訂單.md)完成付款、配送、發票與送出訂單。訂單成立後若要查詢、修改或處理客訴，改看[訂單管理](訂單管理.md)。

## 6. 常見注意事項

| 情況 | 處理方式 |
|---|---|
| 查不到商品 | 清除前後空白、確認銷售編號／關鍵字與通路，再重新查詢。 |
| 商品不能加入購物車 | 檢查可接單量、商品通路、規格是否完整與是否需要指定客戶。 |
| KIT 商品規格不完整 | 回到商品明細補齊顏色／尺寸／款式，再重新加入。 |
| 購物車沒有商品 | 回到接單作業查詢商品；不要直接進入空購物車結帳。 |
| 近期已有相同商品 | 先閱讀近期訂單提示，向客戶確認是否仍要新增。 |
| 需要查商品話術 | 從銷售編號進入商品話術，確認商品亮點、價格優惠與成交核對內容。 |
