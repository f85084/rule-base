# RuleBase

RuleBase 是 CSP / MSG 等專案的**操作文件與資料索引延伸庫**。

## 目標

將 `project-docs`、需求單與其他來源中的實用資訊，整理成可查詢、可維護、可追溯的操作文件。

## 核心用途

1. **操作文件** — 整理日常操作、規則快查與排錯手冊。
2. **專案索引** — 依 CSP／MSG 分類文件、測試資料與需求單對照。
3. **來源追溯** — 保留原始文件、來源連結與待確認事項。

## 與現有文件的關係

RuleBase **不取代** `project-docs/projects/CSP/data/business-flows` 等現有文件，而是作為延伸整理層：

- `project-docs` → 完整業務流程與技術文件
- 需求單 → 功能輪廓與文件對照
- 原始 PDF → 操作資料與環境資訊
- RuleBase → 操作摘要、規則快查、排錯與索引

## 目錄結構

```
RuleBase/
├── docs/               # 操作文件、索引、架構與工作流程
│   ├── csp/            # CSP 文件
│   ├── msg/            # MSG 文件
│   ├── architecture/   # 共用架構與專案邊界
│   └── workflows/      # 共用文件整理流程
├── data/               # 靜態資料與規則定義
│   ├── rules/          # 規則與領域知識結構
│   ├── samples/        # 測試資料樣本
│   └── sources/        # 原始參考文件（PDF、OneNote 匯出檔等）
├── engine/             # 未來可能使用的規則執行區
├── tools/              # 未來可能使用的匯入與驗證工具
└── scripts/            # 一次性或輔助腳本
```
